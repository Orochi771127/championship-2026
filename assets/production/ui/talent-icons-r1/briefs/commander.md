# Art request: talent tree icons - Commander line (battle: party command, resonance, finishing moves) (2026-11-18)

From Claude (systems / UI) to Codex (art), at the Owner's direction: the tamer talent screen becomes a node tree
of ICONS (tap a node and it lights up; press and hold to read what it does). Each icon must say its idea with
no words.

## Style (must match the set you already drew)

Look at `reference/*.png` first: `star-on`, `lock-level`, `exp-crystal`, `evolve-ready`, `tamer-level-badge` are
your own stickers from the last request, and `hud.png` is the live arcade HUD. Same language exactly:

- Chunky arcade sticker: thick dark ink outline (#0e101a), flat saturated fills with ONE lit facet and one small
  white glint, a short hard drop shadow straight down. No soft airbrush, no photo texture, no 3D render.
- ONE clear object per icon, centred, even padding, readable at 28 px and at 64 px. No text, letters or numbers.
- This line's accent colour: royal blue #4d8dff / #a9c8ff. Use it for the main object; gold #ffc531 and white for highlights.
- Original designs only. No logos, characters or symbols from any existing game or brand. Creatures, where an
  icon needs one, are a simple original silhouette (a paw, a horn, a tail), never a recognisable character.

## Deliverables

Transparent RGBA PNG, 256 x 256 each, one file per row, written to `out-commander/` with exactly these file names:

- `line-commander.png` : the line emblem: a commander flag on a short pole
- `commander.syncTraining.png` : sync training: two arrows looping into a circle around a spark
- `commander.opening.png` : first move: a lightning bolt leaving a starting block
- `commander.goodMood.png` : good mood: a simple smiling face badge with a sparkle
- `commander.lumen.png` : Lumen resonance: a radiant heart with light rays, mint green #34d399
- `commander.iron.png` : Iron resonance: a heavy cog-shield, steel grey #94a3b8
- `commander.rift.png` : Rift resonance: a spiral rift or vortex, violet #a78bfa
- `commander.charge.png` : charge up: a battery filling with a bolt
- `commander.adversity.png` : adversity: a cracked shield that still holds, with a small flame
- `commander.finisher.png` : finisher: a burst star with a strike slash through it
- `commander.pureFaction.png` : KEYSTONE pure faction: three identical banners in a row, gold rim
- `commander.triColor.png` : KEYSTONE tri-colour command: three banners in mint, grey and violet fanned out, gold rim

Also write `out-commander/NOTES.md`: one line per file on what was drawn.
