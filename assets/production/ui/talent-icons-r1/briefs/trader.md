# Art request: talent tree icons - Trader line (economy: coins, crystals, supplements, bargains) (2026-11-18)

From Claude (systems / UI) to Codex (art), at the Owner's direction: the tamer talent screen becomes a node tree
of ICONS (tap a node and it lights up; press and hold to read what it does). Each icon must say its idea with
no words.

## Style (must match the set you already drew)

Look at `reference/*.png` first: `star-on`, `lock-level`, `exp-crystal`, `evolve-ready`, `tamer-level-badge` are
your own stickers from the last request, and `hud.png` is the live arcade HUD. Same language exactly:

- Chunky arcade sticker: thick dark ink outline (#0e101a), flat saturated fills with ONE lit facet and one small
  white glint, a short hard drop shadow straight down. No soft airbrush, no photo texture, no 3D render.
- ONE clear object per icon, centred, even padding, readable at 28 px and at 64 px. No text, letters or numbers.
- This line's accent colour: amber #ffb020 / #ffe08a. Use it for the main object; gold #ffc531 and white for highlights.
- Original designs only. No logos, characters or symbols from any existing game or brand. Creatures, where an
  icon needs one, are a simple original silhouette (a paw, a horn, a tail), never a recognisable character.

## Deliverables

Transparent RGBA PNG, 256 x 256 each, one file per row, written to `out-trader/` with exactly these file names:

- `line-trader.png` : the line emblem: a coin pouch tied with a cord
- `trader.haggle.png` : haggle: a price tag cut by a slash
- `trader.bounty.png` : bounty: a stack of coins with a small star
- `trader.crystal.png` : crystal: two cyan EXP crystals with a plus spark
- `trader.patrol.png` : patrol: a small patrol pod or drone with a radar arc
- `trader.tower.png` : tower: a tall signal tower with a flag on top
- `trader.regular.png` : regular customer: a stamp card with a few stamps
- `trader.belt.png` : supply belt: a belt with three pouches
- `trader.scavenge.png` : scavenge: a hand picking up a small supply box
- `trader.appraisal.png` : appraisal: a balance scale with a coin on one side
- `trader.bountyHunter.png` : KEYSTONE bounty hunter: a target ring around a coin, gold rim
- `trader.peddler.png` : KEYSTONE peddler: a travelling merchant backpack with rolled goods, gold rim

Also write `out-trader/NOTES.md`: one line per file on what was drawn.
