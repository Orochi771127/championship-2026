# Art request: talent tree icons - Hunter line (the hunt: ropes, nets, tracking wild partners) (2026-11-18)

From Claude (systems / UI) to Codex (art), at the Owner's direction: the tamer talent screen becomes a node tree
of ICONS (tap a node and it lights up; press and hold to read what it does). Each icon must say its idea with
no words.

## Style (must match the set you already drew)

Look at `reference/*.png` first: `star-on`, `lock-level`, `exp-crystal`, `evolve-ready`, `tamer-level-badge` are
your own stickers from the last request, and `hud.png` is the live arcade HUD. Same language exactly:

- Chunky arcade sticker: thick dark ink outline (#0e101a), flat saturated fills with ONE lit facet and one small
  white glint, a short hard drop shadow straight down. No soft airbrush, no photo texture, no 3D render.
- ONE clear object per icon, centred, even padding, readable at 28 px and at 64 px. No text, letters or numbers.
- This line's accent colour: forest green #2fbf71 / #8be9b0. Use it for the main object; gold #ffc531 and white for highlights.
- Original designs only. No logos, characters or symbols from any existing game or brand. Creatures, where an
  icon needs one, are a simple original silhouette (a paw, a horn, a tail), never a recognisable character.

## Deliverables

Transparent RGBA PNG, 256 x 256 each, one file per row, written to `out-hunter/` with exactly these file names:

- `line-hunter.png` : the line emblem: a lasso loop with a paw print inside
- `hunter.breath.png` : long breath, more hunt time: an hourglass with a leaf

- `hunter.herdSense.png` : herd sense: three paw prints in a cluster
- `hunter.appraise.png` : a good eye for quality: a magnifying glass over a gem
- `hunter.wildSense.png` : wild sense: an animal snout sniffing with scent lines
- `hunter.swift.png` : swift step: a boot with speed streaks
- `hunter.steady.png` : steady hand: a gloved hand holding a taut rope
- `hunter.thrift.png` : save ammo: a net-shot capsule with a recycle arrow
- `hunter.keenEye.png` : KEYSTONE keen eye: a large eye inside a diamond frame, gold rim
- `hunter.chainHunt.png` : KEYSTONE chain hunt: two lasso loops linked like a chain, gold rim

Also write `out-hunter/NOTES.md`: one line per file on what was drawn.
