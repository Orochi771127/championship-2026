# Move icons, batch 7 of 42 (original game: Cyber Partner: Tournament), 2026-11-18

Use your built-in image generation tool. Make each item below as its OWN separate square PNG
with a TRUE TRANSPARENT background (real alpha channel; no checkerboard, no backdrop, no floor,
no shadow plate, no frame, no text, no letters, no numbers, no logos, no watermark).
Save each result into the `out/` folder of this directory with exactly the file name given.

These are MOVE ICONS for a creature-battle game: each one shows the move itself (the attack or
effect, not the creature that uses it). They are shown at 28-48 px on battle move buttons. So:
- one bold, simple subject that tells what the move does, strong silhouette that reads at 32 px;
- read the move's Chinese and English name and draw what it describes (a bite = jaws, a cannon =
  a blast leaving a muzzle, a rain of stars = falling stars, a slash = a crescent cut, etc.);
- thick clean dark outline (#141824-like), 2-3 tone cel shading, one glossy highlight;
- saturated colours; the colour named for each move is its dominant colour;
- subject centered, filling about 85% of the canvas;
- EVERY icon in this batch must be clearly different from the others (different subject or
  composition), even when two moves share a colour and a delivery;
- the whole set must look like ONE family (same outline weight, same lighting from top-left).
Style reference: the glyphs in `../ref/` — Japanese cel-shaded game icon, neon cyber accents.
Original design only: never imitate any existing brand, game, franchise symbol, creature or
real-world logo.
