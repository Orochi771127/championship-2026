## 接入狀態（2026-10-29）

- 資料檔：`src/data/championship/product-species-originals.r1.json`，由 `src/championship/contracts/productOriginalSpecies.js` 驗證。驗證項目包括：ID、曲線範圍、單一種族、第一招為近戰、只能進化到下一階、插入分支不超過 5 條。
- 物種查詢：`productSpeciesRecord(231–244)` 會回傳各自的紀錄。`isKnownSpeciesIndex` 仍是 false，所以登錄、捕捉、對戰、養成都不會接受這 14 隻。
- 進化：養成引擎讀的規則表會透過 `withReadyProductOriginals` 合併「已就緒」角色的分支與插入分支。目前沒有角色就緒，規則表與原生逐位元組相同。
- 就緒門檻：要標成 runtimeReady，每招都必須綁定對戰招式紀錄並有五語名稱。另外，只要有任何一隻被標成就緒，載入就會失敗（`PRODUCT_ORIGINAL_ACTIVATION_NOT_WIRED`），直到登錄、捕捉、對戰的接線完成為止。
- 圖鑑仍只顯示美術，不顯示能力與招式。

- 對戰：在對戰招式表新增招式紀錄並綁定 `battleMoveRecord`，同時處理 VFX 與四語招式名。
- 捕捉：若要能捕捉，需要補捕捉資料；目前設計是只能靠進化取得。
- 動畫：14 隻都還沒有一般遊戲與 Data Arena 動作，沒有動畫前不能開放遊玩。
- 可登錄總數會從 218 變成 232；只有全部真正接入後才能這樣宣稱。
