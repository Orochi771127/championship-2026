# 夥伴心情系統（已實作）

日期：2026-11-16　狀態：**已實作**。Owner 2026-11-16 把設計與四項決定全權交給 Claude（「這些都交給你決定」），本文件記錄做了什麼、怎麼決定。屬 OWNER_APPROVED_ADAPTATION。

## 1. 目標

- 點一下夥伴，就能從臉孔看出牠現在的心情。
- 心情是照顧的回饋：照顧得好，對戰有一點點加成；放著不管，有一點點懲罰。永遠不會讓夥伴不能出戰。
- 不新增第二套飢餓、親密或計時器：只讀原作已有的欄位，另算一個不存檔的「心情分」。

## 2. 原作欄位（只讀，依原作程式碼確認）

| 欄位 | 原作意義 | 原作怎麼變 |
|---|---|---|
| `020` 親密度 0–100 | 卡片上的愛心（每 20 一顆） | 點擊 +1（10 分鐘冷卻）、隨時間成長、對戰勝利 +1／+3／+10；生病 −5 |
| `01c` 病氣壓力 0–100 | **越高越糟**：≥90 立起壓力旗標 `404`，到 100 生病（`138`） | 吃到腐壞食物 +50、吃飽 −10、被拿起 −1、親密成長時 −1、治好病歸零 |
| `040` 受傷壓力 0–100 | **越高越糟**：超過 30 時訓練可能受傷（`134`） | 對戰輸或倒下 +10、蛋白質過量、睡眠不足 +1、治好傷歸零 |
| 成長旗標 `418` | 肚子餓 | 原作成長流程 |
| `134` / `138` | 受傷／生病 | 原作照顧流程 |
| `00c` / `178` / 狀態 4 / `13c` | 疲勞與睡眠 | 原作睡眠流程 |
| 籠舍適居 | 喜歡、普通、不適應 | 原作籠舍喜好表；髒亂降一級 |

> 草案初版把 `01c` 誤寫成「開心值」；依原作程式碼更正為病氣壓力（高 = 不好）。
> 原作對戰**不讀**以上任何欄位，所以「心情影響對戰」是新規則。

## 3. 心情分（`partnerMoodScore`，不存檔）

```
心情分 = 親密度 × 0.4 − 10
       − max(0, 01c − 30) × 0.7      （病氣壓力）
       − max(0, 040 − 30) × 0.5      （受傷壓力）
       − 受傷或生病 40、肚子餓 25、想睡 15、籠子髒 10
       ± 籠舍（喜歡 +20、不適應 −20）
       + 體力 ≥ 90% 時 +5
       + 30 分鐘內的時刻（和朋友打招呼 +8、撿到東西 +5、夜裡被吵醒 −15）
限制在 −100～+100
```

| 級別 | 心情分 | 卡片心情條 |
|---|---|---|
| 絕佳 | ≥ 45 | 5 格（金） |
| 好 | 15～44 | 4 格（綠） |
| 普通 | −14～14 | 3 格（藍） |
| 差 | −44～−15 | 2 格（橘） |
| 很差 | ≤ −45 | 1 格（紅） |

例：親密度 50、普通籠舍、沒有需求 → 10（普通）；親密度 100、住喜歡的籠舍、體力滿 → 55（絕佳）。

## 4. 心情種類與臉孔

需求優先（不舒服、肚子餓、想睡、音樂、撒嬌）；沒有需求時依級別：絕佳 → 精神百倍、好 → 開心、普通 → 平穩、差或很差 → 心情低落（新增）。

點擊時依心情輪流出現其中一張像素臉孔（18 張，原創，不用 emoji 字型；事件序號挑臉，不用亂數）：

| 心情 | 臉孔 |
|---|---|
| 撒嬌 | 愛心眼、親親、害羞、愛心 |
| 開心 | 露齒笑、笑出淚、眨眼、眨眼吐舌、瞇眼吐舌、微笑、音符 |
| 精神百倍 | 星星眼、露齒笑、瞇眼吐舌、笑出淚、閃光 |
| 平穩 | 微笑、害羞、眨眼 |
| 肚子餓 | 好吃、流口水、肉 |
| 想睡 | 打哈欠、想睡、Zzz |
| 不舒服 | 冒汗、感動、含淚笑 |
| 心情低落 | 含淚笑、冒汗、感動 |
| 被吵醒／遇到對手 | 生氣青筋、小惡魔、閃電 |

## 5. 心情對對戰（`moodBattleProfile`，比照同步等級）

只在開戰時套在夥伴的**複本**上，對戰結束由原本的同步還原流程把體力、技力上限與曲線階數換回存檔值；存檔、原作欄位、對戰代碼不會留下加成。

| 級別 | 自動對戰 | 數據競技場 |
|---|---|---|
| 絕佳 | 技力 +10%、攻擊曲線 `084` +1 階 | 夥伴戰力 ×1.04 |
| 好 | 技力 +5% | ×1.02 |
| 普通 | 無 | 無 |
| 差 | 技力 −5% | ×0.98 |
| 很差 | 技力 −10%、速度曲線 `08c` −1 階 | ×0.96 |

**Claude 的四項決定**

1. **要不要影響對戰**：要，但只在 ±10% 內，也不動生命值，不會決定勝負。
2. **心情差要不要懲罰**：要，但比加成更輕（只有「很差」才動曲線），讓照顧有意義又不挫折。
3. **「撐住」「鬧脾氣」**：**不做**。兩者都要改原作的自動對戰流程，會讓重播與原作對照失真；「鬧脾氣」也容易讓玩家覺得被懲罰。之後若要做再另開一批。
4. **頭銜賽、錦標賽**：只套「普通～好」（絕佳當好算、差和很差當普通算），避免照顧時間決定比賽。

**不看心情的對戰**：密碼對戰、連線對戰、線上對戰（與同步等級相同，`sync` 為 null 時一律普通）。

## 6. 讓心情變好

摸摸（親密 +1）、餵食解餓、清潔、放進喜歡的籠舍、讓牠睡飽、別在夜裡吵醒、治好傷病（病氣與受傷壓力歸零）、打贏比賽（親密上升）、和朋友打招呼、散步撿到東西。

## 7. 介面

1. 點擊夥伴：頭上冒像素臉孔。
2. 夥伴卡第二排：心情臉 + 五格心情條 + 愛心；長按／說明文字寫出級別與原因（例如「心情差：肚子餓、籠子髒」）。
3. 出戰選夥伴：每隻旁邊顯示心情臉與級別。
