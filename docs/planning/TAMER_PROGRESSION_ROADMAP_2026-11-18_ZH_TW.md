## 1. 這些東西怎麼扣在一起

```
抓同種拍檔 ──融合──▶ 拍檔等級（同步 EXP）＋星級進度
                         │
                         ├─ 等級到門檻 ──▶ 可以進化（走哪條分歧，仍看原本的種族／素質條件）
                         └─ 星級 ──▶ 等級上限
打六大戰區、推進戰線 ──▶ 結晶 ──灌注──▶ 馴獸師經驗 ──▶ 馴獸師等級
                                                      ├─ 天賦點
                                                      ├─ 商店與狩獵解鎖（補上頭銜階級太慢的問題）
                                                      └─ 技能卡池（天賦線投入點數解鎖）
```

拍檔靠「抓同種來融合」變強，馴獸師靠「打關卡拿結晶」變強，兩條線不再搶同一種資源。

## 4. 星級：Claude 的建議（R3 依此實作）

會好玩，但不要做成純機率。

- **用進度條取代「有機會」**：每融合一隻同種，星級進度 +1；資質越高的素材加越多。集滿就升一星。純機率會讓玩家餵了十隻還沒升星，這種挫折感不值得。
- **星級給的是「上限」，不是直接加數值**：每升一星，等級上限提高（例如 1 星 Lv.10、2 星 Lv.20……5 星 Lv.50）。這樣星級、等級、進化門檻是同一條路：想進化要等級，想要等級要星級，想要星級就去抓同種。
- **不進轉蛋**：星級進度只能靠玩出來，不能抽。
- 具體數字在 R3 動工時用現有的捕獲量與融合經驗表校正，並寫進契約。

## 5. 推進戰線：做成自己的玩法
