# 六角通路與搭檔探索

Owner 2026-10-21 明確要求將提案 3、5 做入現有系統，保留六角、原有遮擋、直／橫／電腦介面。這是 `OWNER_APPROVED_ADAPTATION`，不是原作行為還原。沿用現有牧場、個體、Shop 庫存與唯一存檔。

## 設計決策

Owner 後續取消六方向旋轉：所有籠子維持固定方向，六個相鄰邊仍可依接路條件連接。舊測試存檔方向由相容移轉清除；旋轉圖與操作不進公開版本。

- 建造 → 可讀通路 → 搭檔散步 → 回來分享發現。配置的回饋是探索選擇，不是把搭檔變成產能倍率。
- 同類、同高度、真正共邊才能候選接通；依原有 96×112 六角輪廓與 96／88 節距，不改拖曳／相機。
- 從兩側原有可走格找出口，只准在共同邊界附近補上無主的窄縫；絕不挖掉有主地塊內的不可走格。無安全出口時保留封閉。
- 通路畫在地表層；前景物件及搭檔仍共用原本深度排序。通路、尋路與視覺必須使用同一份連接資料。
- 地圖編輯確認後重建導航；每個散步意圖只求一次路徑，逐幀沿路走，不能每幀重掃百格。
- 探索是拜訪，保留居住地、訓練與容量歸屬；餵食、拖曳、睡眠等原有活動可以中止散步。
- 整座牧場每兩小時累積一份發現，最多存十二份（一天）；線上與離線相同，不依購買地塊／搭檔數量倍增。
- 發現不過期，沒有每日連續登入、錯過罰款、付費加速。滿了只是休息。食物／少量金幣／稀有營養補給進入既有 Shop 庫存。
- 領取須與扣除待領內容一起完成持久化；庫存滿保留未領物品，寫入失敗不扣待領、不發重複獎勵。
- 喜好只影響探索行為、休息與敘事。這批不加入絕食、生病或破壞地塊的懲罰。

- [Factorio 開發日誌 317](https://www.factorio.com/blog/post/fff-317)：區域連通不能代替細部障礙判定。本作借用區域＋細格驗證原理，並未宣稱使用同一演算法。
- [Nintendo 岩田問 New Leaf](https://iwataasks.nintendo.com/interviews/3ds/animalcrossing-newleaf/0/1/)：遊戲配合玩家生活時間。兩小時／十二份與無到期機制是本作設計值。
- [Project Horseshoe 2017 cozy design](https://www.projecthorseshoe.com/reports/featured/ph17r3.htm)：安全、舒適與低壓探索。保留發現與自主散步，不增加焦慮維護。

## 驗收

真實地圖同類／異類、六方向、高度差、內部障礙、版邊不誤連、移走重建、百格容量；路徑每一段合法，原有遮擋契約保留。收益測試含離線上限、時鐘倒退、存檔重讀、庫存滿、重複領取與存檔失敗。瀏覽器正常選單檢查直向、橫向、桌面及截圖；不得將模擬測試宣稱實體手機或公開版驗收。
