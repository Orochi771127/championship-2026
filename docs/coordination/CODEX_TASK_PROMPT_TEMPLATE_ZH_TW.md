# 可重用的任務指令

把下面的任務內容換成這次實際要完成的工作即可，不必每次貼完整專案規則。全域與 repo 的 AGENTS.md 保留常駐規則；具體任務決定範圍與完成條件。

```text
請處理這個任務：〔具體工作與希望完成的結果〕。

先確認正式 repo、Git 狀態與適用 AGENTS.md，再依 docs/README.md 讀取本次相關文件。
原作重建優先；未知保留 UNKNOWN_REQUIRES_TRACE。現代化候選計畫不是施工授權。
在本次已授權範圍內完成必要實作、驗證與修正，保留其他 Agent 的修改。
若本次只要求唯讀盤點，就只回報。未有適用授權不 commit、push、merge 或 deploy。
用繁體中文回報結果、驗證與尚未解決的限制。
```

如需續接未來現代化工作，先讀 `docs/planning/CHAMPIONSHIP_POST_PARITY_MODERNIZATION_PLAN_ZH_TW.md`，再依當次 Owner 指定的 bounded POC 工作；讀到此計畫不會自動批准 Gate 或其他場景實作。

修改本機指令檔不會撤回舊聊天中已貼出的指令。新的任務使用這個短範本，並從正確 repo 重新載入指令；不要再貼舊的「每次必讀全部文件／跑全部測試」版本。
