## 美術目標與製作方式

1. 優先盤點現在遊戲真正載入的圖、原創 `.blend`、物件、材質、相機、光源、遮擋層與行走資料，建立「地圖 ID → 現行素材 → 原檔 → 參考圖 → 待修問題」清單。涵蓋全部可配置籠子並檢查固定待機區；不要把候選 refined.blend 當成已驗收原圖。
2. 使用適合的 game-design-theory、game-asset-production、game-ui-design、game-playtest／效能 skill，以及現有 Blender MCP／Blender 原檔。依實際可用工具製作，不為了使用外掛而安裝無關工具。現有原檔不足時先查來源清單；不要改用圖片拉伸遮掩問題。
3. 沿用目前遊戲的微縮、風格化美術，統一比例、相機、光源方向、陰影軟硬、色彩與材質語言。避免不同籠子各自像不同遊戲；不要為追求寫實而破壞搭檔可讀性。
4. 材質要看得出草地、泥土、石材、橡膠、木材、塗裝金屬與水面的差異。使用適當粗糙度、法線／微表面、倒角、接觸陰影與有理由的使用痕跡；不把全部表面做成塑膠，也不靠滿畫面的噪點增加細節。
5. 光影要讓地面、設備、植栽與搭檔有清楚層次。統一主光、補光、環境光和曝光，檢查黑位、過曝、漂浮感與拼接後光影差異。需要拆出前景、陰影、動態物件時，沿用既有輸出與遮擋管線。
6. **我允許調整每個物件的位置及擺設。** 每張圖建立主視覺焦點、次要功能區與小型生活細節，改善空洞、重複和隨機散放。增加有用途、有主題的物件，例如器材收納、休憩位置、維護痕跡、合理植栽與服務動線。活動空間和道路保留呼吸感，不能為了填滿而塞滿裝飾。
7. 有我的新參考圖，就以新設計修舊模型。CM02／CM30 保留 Claude 製作的綠色運動公園方向；CM05／CM34 依新橘黑地板、紅黑器材健身房參考改善。沒有參考圖的籠子，由你依主題及整體美術規範設計，先做小樣實際比較，再批次展開。
8. 先做代表場景：健身房大／小拼接、目前運動公園，以及各一張水景和機械場景。先自行完成原版／改版、細節／全景、單塊／拼接、搭檔在場的比較，修正明顯問題後再分批完成其他籠子。每一批要逐張看圖，不只檢查檔案數與 hash。

## 幾何、路線與遮擋

9. 地塊占格、原生尺寸、透明邊界、相機與比例以目前權威資料為準，不另造一套六角格演算法。單格與多格設施都要留在實際占格聯集內，含凹形缺口；擂台、球場、房屋不可跨出格子。禁止靠非等比例壓扁、拉斜、裁掉設備、隱藏越界零件處理問題。
10. 舊模型可能使用配合固定視角的特殊基底。逐物件查證再修，不可對所有模型套同一校正矩陣；新版 CM30 球場本來就是正常直角。需要重建的設備保留合理尺度與完整結構。
11. 同類同高度地塊及對應大小地塊相接，要有清楚可見、實際可走的入口與路徑。保留活動區，物件不可堵住連接點。顯示可通行的地方，導航與碰撞也必須可通；遮擋物仍應正常阻擋，不能為接路關掉整片碰撞。
12. 每次移動大型物件，都同步核對阻擋、clearance、路徑、前景深度與搭檔遮擋。檢查搭檔從物件前面、後面和鄰地走過，不可穿模或整隻消失；使用真實遊戲中的既有角色，不用替身圖假裝整合完成。

## 讓場景活起來，但維持手機可玩性

13. 有機械手臂就以合理關節、樞軸和循環節奏運動；水流依場景合理流動，水面波紋、葉片擺動、少量燈號可增加生命感。只動畫應該動的部分，固定設備不應整張一起晃。動作不能撞到搭檔路徑，不能用隨機閃光冒充設備運作。
14. 動態依現有 Pixi／ticker／素材管線整合；先量測再選逐幀、分層或 shader，不另建第二個遊戲、存檔或 renderer。量測可見場景與大量地塊的幀時間、draw calls、記憶體和下載量；遠處／不可見處應降頻或停止更新，支援省電與減少動態設定。
15. 檢查手機直向 390×844、手機橫向 844×390、桌面 1280×720，以及現有 100%／70% 縮放兩級。保留育成拖動、雙指／滾輪縮放及較快的攜帶鏡頭；美術不得擋操作。瀏覽器模擬要如實標註，不能當成實體手機效能驗收。
