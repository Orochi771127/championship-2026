# 數據競技場接力對戰：角色配招符合屬性（第一階段，2026-10-28）

Owner 指示：「盤點我們的角色幫他們配招要配適合的屬性還有招式，就像不可能草系會發飛彈」；幼年期 I／II 不進新模式，其餘都能選。Owner Direction：`ARENA_RELAY_KITS_20261028`。工作樹 `arena-relay-kits-20261028`（分支 `feat/arena-relay-kits-20261028`，從 origin/main ab387a86 切出），**未 commit、未 push、未部署**。

## 結果

- **可選角色**：沿用 196 隻（ROM 成長期至究極體 194 隻，加上擴充 229、230）。蛋、幼年期 I／II 原本就排除，已核對無遺漏。
- **屬性重判**：舊屬性有 105／192 隻和角色自己的招式顏色不符，例如花系皇后被設成物理、花風妖精設成水、炎鳥設成冰。現在改由 `scripts/build-data-arena-relay-kits.mjs` 依角色**自己招式的原始特效或核准名稱顏色**投票決定，與 main 相比共修正 114 隻（已含下節名稱衝突修正後的調整）。三位錦標賽拍檔（034、061、064）保留原設計套組的屬性。
- **配招**：五選三的前 1–3 招是**角色自己的招式**，顯示核准的五語招式名稱。機制依招式的特效風格決定，例如 seed → 種子彈、vine → 延遲藤縛、missile → 擊退重彈、shell → 護盾。火色招式會點燃，冰色招式會緩速、結冰。數值不隨階段改變。其餘招式從**同屬性池**補滿。
- **屬性池清理**：自然池原本借了衝浪和冰盾，地／暗池借了火盾，雷池借了光系突進和光盾，物理池借了光盾。這些已換成 8 招新的同屬性招式：水幕盾、岩壁盾、電磁盾、樹皮盾、暮影盾、鋼鐵盾、雷光突進、棘刺突進。
- **普攻**：名稱改成角色自己的普通攻擊。
- **特效主題**：`move-vfx-themes.r1.json` 依新屬性重新產生，有 49 列基礎近戰招式的顏色跟著改變。
- 每隻角色的完整清單見 [ROSTER_KITS_ZH_TW.md](ROSTER_KITS_ZH_TW.md)。

## 第二階段：特效（只改呈現，不改規則）

- **依招式風格畫投射物**：新增 12 張原創程序貼圖（葉片、種子、棘刺、孢子、飛彈、子彈、水滴、閃電、岩塊、風刃、暗球、音波），加上原本 4 張，對應 23 種風格。招式池的招式也都有指定風格，不再只是換色。
- **普攻依施放者屬性**：遠程普攻（吐息、射擊、光彈、翼風）改成角色屬性的樣子，例如火系顎型角色吐火球、自然系吐種子、物理系砲台射子彈；近戰普攻依屬性上色。
- **命中家族**：依風格噴出星爆、葉片、岩塊（帶旋轉與重力）、水滴、火花、碎晶、霧團、爆炸環或音波環。
- **頓幀**：傷害 ≥22 時停 60 ms，≥40 時停 80 ms，只凍結角色畫格，模擬照常進行；減少動態設定下關閉。
- **蓄力光**：遠程招式前搖時，手前方的光球會逐漸變大。
- **光束連線**：光束、聖光、雷系射擊在 0.45 秒內，從施放者手上連到投射物，並有波動漸隱。
- **狀態顯示**：燃燒冒火星、定身時腳下出現冰環、緩速時拖出藍霧。
- **音效**：普攻音效也依角色屬性。
- 參考技能：專案的 `juicy-monster-ui`（頓幀只凍結畫面、只由真實事件觸發、尊重減少動態）和 `game-feel`（依重要度分級、短暫誇張後回到靜止）。

驗證：新測試 8／8 通過，其中一條檢查 196 隻角色的每一招都對應到有效風格與貼圖、普攻依屬性；受影響的 17 個測試檔 215／215 通過；瀏覽器實測機冕龍、花刺皇后、闇巡零狼、潮鑄海將出招截圖，沒有 console 錯誤；Relay 瀏覽器閘門 13／13 通過（完整對戰勝利、育成存檔不變）。
