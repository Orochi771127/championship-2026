## 循環點實測

| 檢查 | 結果 |
|---|---|
| Gemini 的 25.6 s → 128.0 s（時間差 102.4 s） | 波形相關 0.02，不是重複段，不採用 |
| 實際重複 | 時間差剛好 51.2 s（150 BPM 的 32 小節）。51.2–70.4 s 與 102.4–121.6 s 逐小節相關 0.57–0.74 |
| 121.6–128 s | 不重複的結尾段 |
| 採用的換手點 | 120.0 s 接回 68.8 s。這是可用區間內最晚的小節線，前後 0.4 s 窗口相關 0.81 / 0.80，兩邊的重拍都在 +0.1 s |

- 第一次進入會從 0 播到 120.0 s，之後每圈從 68.8 s 播到 120.0 s，長 51.2 s。
- 重複段很接近，但不是逐樣本相同（AI 生成曲的再現段常見），所以交叉淡化設為 0.1 s，比商店曲的 0.05 s 長。
- 原曲 121.6–128 s 的收尾段在循環播放時不會出現。
