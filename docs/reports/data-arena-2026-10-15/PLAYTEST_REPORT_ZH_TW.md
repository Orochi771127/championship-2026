# Data Arena 遊玩測試報告（2026-10-15）

格式借鏡 Claude-Code-Game-Studios v1.0.0（commit `984023ddac0d5e27624f2baacde6105e45de375f`，MIT）的 playtest-report 結構，內容為本專案原創。

## 場次資訊

- **建置**：分支 `claude/busy-tesla-o4mkxk`（合併 main `2e706013` 後），原始碼與 Pages 建置產物各測一次
- **測試者**：自動駕駛（`tests/championship-data-arena-qa-bot.cjs`，只讀觀測，10 Hz 決策，透過 Playwright 送真實鍵鼠／觸控事件）＋開發者逐張截圖審查。**沒有真人外部測試者**
- **平台**：headless Chromium 141（SwiftShader 軟體 WebGL），1280×720 桌面、390×844 手機模擬（觸控、DPR 3）
- **輸入**：鍵盤＋滑鼠；觸控雙搖桿＋按鈕
- **場次**：4 次完整對局＋5 次連續重開＋2 次離開再進入＋1 次手機觸控短局

## 測試重點

入口到結算閉環、雷射手感、元素交互是否被看見且影響路線、搭乘渡河、升級差異化、預告公平性、觸控與版面、資源釋放。

## 第一印象（前 5 分鐘，開發者審查）

- **目標是否清楚**：是。簡報一行目標＋HUD 頂部常駐目標（例：「撲滅火源核心 1/3」、「占領南碼頭信標 0/3（凍橋或搭乘渡河）」）；階段前 3 秒橫幅預告。
- **操作是否清楚**：桌面是（簡報 6 行）；觸控是（3 行＋按鈕標籤）。
- **注意**：首局可能不知道「火源核心只能用水」——已在 0:42 預告橫幅與核心旁圓形預告中直接寫出按鍵。

## 流程

### 做得好的
- 雷射有重量感：轉速上限、熱量條隨色溫變化、過熱蒸氣與鎖定，命中點閃光；掩體確實截斷光束（截圖 `desktop-full-combat`）。
- 元素交互可讀且改變路線：火蔓延成片並把敵人導向繞路；潮湧熄火留下濕地；冷凍艙凍出 3 格寬冰橋，碎裂前閃爍＋音效＋提示（`seed3-desktop-full-ice`）。
- 搭乘渡河是明確的第二路線：騎在隊友背上游過水道仍能開火（`desktop-full-ride`）。
- 預告公平：所有敵彈至少 0.5 秒線形預告（單元測試釘住），光環缺口以綠點標示，守衛重擊有填充式紅圈。
- 觀眾：漂亮閃避、救援、元素連鎖等有不同燈色與跳動波，喝采滿格給 8 秒增益。

### 痛點
- 嚴重度中：掃描風暴＋守衛階段傷害偏集中；已兩度下修並加入目標回血，仍需真人確認（見平衡）。
- 嚴重度低：曾經大型隊友會遮住玩家 → 已改為隊友跟在玩家後上方。
- 嚴重度低：隊友在水中倒下時無法救援 → 已改為倒下即被沖上最近岸邊。

### 驚喜時刻
- 守衛戰中剛凍出的冰橋（「冰橋成形！」）與守衛重擊的紅色預告圈同時出現在玩家腳下，形成「留在冰橋上、還是退回岸上」的即時抉擇（`seed3-desktop-full-ice`）。

### 做得好的

- **雙方都有前搖**：對手每招都有紅色線／扇／圓預告（截圖 `desktop-cup-rival-telegraph`）。ZONE 在前搖就畫出落點圓，之後才延遲爆炸，走出圓即無傷（單元測試釘住）。
- **掩體真的改變攻擊線**：柱子擋住雙方彈道與自動瞄準。對手能量耗盡時會躲到切斷視線的柱後（`desktop-cup-rival-cover`），回滿再接戰。
- **緊湊場地**：雙方隨時在射程內，回合 40–85 秒；雙人取景讓對手不出畫面。
- **擊退與撞牆**：被突進或潮浪推向柱子會受傷，被推下水道則落水回岸。站位不再只是遠近問題。
- **輪次節奏**：VS 開場 3 秒（輸入凍結）→ 開打 → KO 2.2 秒 → 對戰表＋三選一 → 下一輪；決賽固定為冠軍對手並切換決賽音樂。
