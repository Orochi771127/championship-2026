# CM19 溫泉、CM20 沙漠美術精修

沿用相符的 editable.blend，原作僅供語意、構圖及物件配置參考。高品質母檔、原作對照、48 幀短預覽及回復版本位於 R:/Projects/Championship2026/cage-art-refinement-20261024/CM19/r1 與 CM20/r4，不進入公開包。

CM19 以暗湯池、濕石岸、竹籬與木桶區分材質。移除舊實心蒸氣球，改為六點低透明度柔邊薄霧；水域頂點遮罩限定波紋及出水口向下流動，岩壁與地面貼圖不平移。薄霧共用一個 draw，不增加動態燈光。CM20 回到兩組後方岩脊、疏落前景石塊及開闊風紋沙地；移除原圖沒有的仙人掌、骷髏、四塊裝飾橢圓覆蓋物和誤套的工業特效。底層落腳地面不變，沙漠刻意維持靜態。

檔案容量與貼圖解碼記憶體分開記錄。以上為桌機網頁渲染器量測與貼圖估算，不是手機記憶體或玩法驗收。多張不同籠子仍累積各自圖集、geometry、陰影與 render target 成本。

已實際看過固定鏡頭並排圖、短動畫首中末幀、相鄰及最右端 wrap 畫面。CM19 水面和地面、CM20 底層地面、所有邊框與相機在母檔中維持精確座標；CM19 24 個支撐三角形重新綁定，最大角點距離 0.000754 world 以下，低於既有 0.001 契約。其他七張的支撐資料（包括 CM18）不變。Reduced motion 穩定，必要載入檢查無 page error。沒有用角色永遠前置或改鏡頭掩飾模型。

本批參考新增 environment-artist / procedural-modeling 技能做層次、疏密與岩石形體調整。ComfyUI 用既有 DreamShaper 8 完成本機沙地研究圖，未使用 ROM 圖片輸入；研究圖太模糊，僅取配色方向，正式沙紋是 Blender 自製程序材質。技能和研究檔均不進公開包。

CM21 候選未通過冰面薄板細線與微小雪帽縮圖自審，獨立歸檔，GLB、支撐資料與新 shader 不隨本批發布。CM01 r3、CM07 r3 保留。角色動畫、戰鬥、狩獵與存檔規則未變。

發布前執行既有 playtest build 與 package validate；部署成功後以 pages-build.json、manifest 及公開 GLB SHA-256 回讀確認，記錄於各 ID 的 PUBLICATION_RECEIPT.json。
