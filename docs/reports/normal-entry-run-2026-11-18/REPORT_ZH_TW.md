## 2. 同日以真實點擊操作過的流程

在同一個隔離來源、同一份 QA 存檔上，用瀏覽器實際點擊：

- 繼續遊戲 → 牧場 → 商店買飼料（90 → 91，金幣 −5，已存檔）。
- 轉蛋單抽（券 10 → 9，獎品已存檔）。
- 儲存並離開 → 標題 → 繼續遊戲（狀態保留）。
- 自由對戰打到結算（獎金 50，錢包 +57，結算頁有「賞金天賦 +7」）。
- 另開同一存檔的第二個分頁會被拒絕，顯示「另一個分頁正在遊玩」。

## 3. 兩次第一次沒過的原因

- **轉蛋驗收**：第一次在合成爐等不到可點的格子而逾時，單獨重跑 26 秒通過。這支腳本的十連抽結果是隨機的，抽到的獎品不夠合成時就會等不到。屬於腳本對隨機結果的依賴，不是遊戲壞掉。
- **503 連三次**：腳本在按下重試、畫面顯示「正在載入夥伴外觀…」的那一刻就判定結束。已改成等到畫面上沒有任何狀態訊息才算結束，重跑通過。

## 4. 沒有驗證的部分

- 實機（iPhone、Android）。
- Safari／WebKit 上的這一輪。
- 頭銜賽：驗收用的牧場時間是凌晨，清單顯示「目前沒有開放的對戰」。這是階級升級節奏的待決事項。
- 整場錦標賽（三輪）用手點完：預覽面板在視窗沒開啟時不跑動畫影格，只跑了對戰驗收腳本的單場。
- 拾荒、鑑價、散步好運、省彈：需要機率或 15–30 分鐘散步，只有規則與程式測試。
- 狩獵結算畫面上的傳承、賞金獵人配合真的賞金信標：只有規則與程式測試。
- 狩獵與對戰場景的 503 情境（牧場跑過；它們共用同一個載入範圍）。
