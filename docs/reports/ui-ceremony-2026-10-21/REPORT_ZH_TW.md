## 1. 為什麼先前預覽仍是舊角色、舊地景與除錯面板

| 現象 | 根因（已核對原始碼與實際請求） |

| 舊角色、舊地景 | 遊戲依**網址**選素材：`src/championship/app/main.js`、`presentation/finalHuntArt20261008.js` 在本機 `127.0.0.1／localhost` 走內部審稿清單（`hunt/final-intake-20261008`、`hunt/original-opus-v1`、`internal-character-review/*`），這些資料夾不在 repo，請求 404 後退回舊授權美術；只有正式網址 `https://orochi771127.github.io/championship-2026/` 才走已核准的新原創素材。先前報告截圖是在本機 dev server 拍的。 |
| 除錯面板 | 先前捕獲截圖使用 `?presentation=developer`（取得野生位置用），會顯示開發者證據欄與場地列表。 |

處理：本輪所有新截圖改為**以建置產物 `dist/github-playtest` 掛在正式網址下**（Playwright 將正式網址的每個請求對應到本機建置檔），遊戲因此做出與正式站完全相同的素材選擇；全程**無 404、無頁面錯誤**、未使用開發者模式。舊截圖（`docs/reports/ui-ceremony-2026-10-15/`）只作為問題證據，不作新版美術基準。
