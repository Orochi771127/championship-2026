# Data Arena 地圖測試版整合

港口 r6、錦標賽 detail-r3 與 interactions-v1 從正常主選單載入，沿用既有 Pixi stage、ticker、模式存檔與相機。港口有分區地面、機械手臂逐格動作、觀眾反應與水流；錦標賽有觀眾、旗幟與獨立水面。四種木箱狀態、燃燒、冰面、跨水與墜落恢復與場地互動一致。只載入目前場地及畫質，解碼最多同時四份，離場釋放場景資源。

本批採最接近專案原圖布局的既有版本。外部畫面只作材質、光影與模型細緻度參考。r7/r9 的倉庫、辦公區與船，detail-r4 的亭子未納入；其原始來源和舊候選保留。美術仍有材質、裝飾、植栽與標線細緻度落差，本次是獲准的公開測試，不代表最終視覺或商業發行通過。

## 驗證

- 本機 portable CI：2,487 通過，0 失敗、跳過；受影響的 Data Arena focused cases：89 通過。
- 公開測試建置與 validate:playtest 通過，10,114 檔；精確 buildId 與 log SHA-256 見 RELEASE_VALIDATION.json。
- 編譯成品透過真正主選單，以 Chrome / RTX 4070 Ti D3D11 操作，52 項通過。涵蓋鍵鼠、觸控、正常版本載入、高低畫質切換、等待載入時禁止提前恢復、背景暫停、縮放、五次重開、減少動態、離場清理、育成存檔逐位元組不變。沒有未預期 console/page/HTTP/request 錯誤。手機為瀏覽器模擬，未宣稱實體手機效能。
- 相同遊戲邏輯的先前完整流程已有 82 項通過，錦標賽三回合勝利、港口實際敗北均保存；本輪為整合回歸，沒有宣稱重新打完完整比賽。
- 一次新增瀏覽器檢查錯把鏡頭搖晃開關當減少動態，已改為系統 prefers-reduced-motion 並正常重進場，修正後通過；產品程式未因此修改。
- Windows 缺乏建立檔案 symlink 權限時，既有 alternate-form 路徑逃逸測試改用私有目錄 junction；Linux 原測試保持，拒絕私有內容的斷言未弱化。

## 來源與範圍

選定素材為專案原創程序建模、材質與動畫姿勢；沒有外部模型、權重、貼圖或 custom nodes。Blender 5.2 以 Python 批次產出；本工作階段未暴露 Blender MCP，未將其誤報為 Blender 不可用。先前 ComfyUI 試驗未納入本批素材。地圖素材的原創依據不替其他既有遊戲資產作權利保證。

可編輯完整 .blend、固定相機渲染來源與必要依賴已存入既有來源包：
[兩張完整場地來源與差異包](https://chatgpt.com/api/library/files/libfile_428514514e4081919011c033a8a0b0cb/download)。來源 SHA-256 見 RELEASE_VALIDATION.json；SELECTED_RUNTIME_FILES.json 列出精確 337 份 runtime 檔，包含沿用的舊版共享圖層。原始工程不放入公開網頁建置。

保留主線 e905b893 的 PR49 籠子購買 UI 與既有夥伴命名。未改一般戰鬥場地、角色、BGM、卡片、50 格／每排 10 格經濟或育成存檔契約。公開建置只更新本批允許路徑的雜湊，不刷新無關資產雜湊。新增檔案 342 份（5 JS 與 337 素材），既有批准輸入改動 8 份。

發布需以 PR 綠燈、main merge SHA、Pages 終態與線上精確檔案核對為準；交付時另附發布回執。

## 後續

舊地圖盤點已確認戰鬥 11 份、育成 37 份、狩獵 30 份輸出及 17 份狩獵地形主檔存在，尚未完成全數精修、真實空間擴大或實體手機驗收。一般戰鬥下一批須先對齊原作物件和可走／不可走／看台／水域界線，再製作。檔案存在並不等於所有外部依賴與異地還原均通過；發布後獨立核對既有備份封裝，不重複製造大型來源包。
