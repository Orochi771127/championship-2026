## 主方案：頁面架構、玩家流程與共用規則

**選擇理由。** 原作的工具列（8 格、兩個子選單）與各畫面結構都有 ROM 或影片證據，Owner 也在 2026-09-03 移除了自行加上的五鍵導覽列。因此主方案不新增常駐導覽，而是讓現有的頁面結構清楚、每頁規則一致，並把首頁上方的空白變成「今日狀態」，讓玩家從牧場就看得到錢與比賽。

```
標題 ─ 繼續遊戲 / 開始新遊戲（有存檔時先確認）
 └─ 牧場（育成首頁）  常駐：狀態列 + 工具列（6 照顧工具・管理・系統）+ 今日狀態（位元幣・今日頭銜賽 ›）
     ├─ 管理：馴獸師資料｜賽程（詳細面板・登錄）｜設施配置（未套用先確認）｜夥伴名單（改名）｜結束今天（確認）
     ├─ 系統：說明（詳細面板）｜儲存並離開｜圖鑑｜商店
     ├─ 系統 › 狩獵：選擇狩獵場 → 狩獵設定 → 狩獵場 → 狩獵結果 → 牧場
     └─ 系統 › 對戰（或 今日頭銜賽 ›）：模式 → 賽事／隊伍 → 對戰（離開先確認）→ 結算 → 牧場／多輪賽事
```

**遊戲循環。** 牧場照顧消耗食物與藥品 → 商店用位元幣補貨 → 狩獵付入場費捕捉新夥伴 → 對戰付報名費贏獎金與階級 → 回牧場。首頁的今日狀態、商店的差額提示、狩獵場的鎖頭與入場費、賽程的階級要求，都在說明這條循環的下一步。

**共用規則（全部畫面採用）**

1. 頁首：標題與開啟它的選單名稱相同；管理類畫面以小字標出所在選單（管理、系統、對戰）；必要時一行用途說明。不再疊加重複標題。
2. 頁尾固定在畫面底部：左邊是離開（「返回牧場」或返回上一層），右邊是唯一的主要動作（金色膠囊）；其他動作是白色斜角條。一層只有一種離開方式。
3. 清單點選後的詳細資訊在原處以底部面板開啟；Esc、「關閉」或點背景關閉，焦點回到原項目。
4. 會覆寫存檔、放棄變更或放棄比賽的操作一律用同一個確認視窗；焦點預設在安全選項，Esc 等於取消。
5. 不能操作時寫出原因與差距（差多少位元幣、需要哪一階級、尚未開放）；操作成功時寫出結果與新數量。
6. 顏色語意：金色是選中或主要動作，紅字是不足或拒絕，鎖頭是未開放，✓ 是已登錄；純文字不使用按鈕外觀。
7. 金額一律千分位加「位元幣」（馴獸師資料保留原作固定位數）；夥伴名稱全遊戲使用夥伴名單的名稱；首頁統稱「牧場」。

## 啟動與試玩路線

```bash
npm run serve
```

開啟 `http://127.0.0.1:8732/championship.html`。若不想動到平常的存檔，改用另一個埠：`CHAMPIONSHIP_PORT=8761 node scripts/serve.mjs`（PowerShell：`$env:CHAMPIONSHIP_PORT=8761; node scripts/serve.mjs`），再開 `http://127.0.0.1:8761/championship.html`。

1. LOGIN → 開始新遊戲，完成命名。首頁左上看「0 位元幣」與「今日沒有頭銜賽 ›」；狀態列是「第 1 日」。
2. 系統 → 商店：看到「持有金額不足，還差 5 位元幣」；返回在左、購買在右。
3. 系統 → 狩獵 → 場地列表：未開放的有鎖頭；點一個鎖頭場地看原因；選「戴納草原」→ 前往狩獵設定 → 開始狩獵 → 返回牧場。
4. 管理 → 賽程：點任一賽事，詳細從下方出現；Esc 關閉。系統 → 說明同理。
5. 系統 → 儲存並離開 → LOGIN：「繼續遊戲」在第一位；點「開始新遊戲」會先確認，選取消後繼續遊戲。
6. 進階存檔（選用，只在 8761 這類另開的埠使用）：`/full-qa-save.html` 的安裝會取代該網址目前的進度（安裝前會下載一份備份），所以不要在平常的 8732 使用。安裝後繼續遊戲，試商店連續購買、設施配置未套用就返回、夥伴名單改名、對戰 › 練習對戰到結算，再把瀏覽器調成 820×1180 看平板版面。
