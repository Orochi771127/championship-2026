# Championship Art Production Pipeline

This document describes the future replacement pipeline. This Art-A audit does not authorize production; a new Owner directive must name a bounded ART-B batch.

## Character

Approved reference → character lock → replacement master → whole-action planning → frame production → bottom-center anchor normalization → atlas → PNG/WebP → runtime manifest → visual QA → human approval.

Keep `rawOriginalSlot` separate from `modernSemanticAction`. Unverified slots retain raw identifiers.

## Maps

Reference topology and functional data → renderer-neutral collision/walkability/occlusion/hotspots → evidence-selected presentation → layered visual exports → seam and alignment QA. Logic grids are debug-only.

## UI

Original function and information hierarchy → mobile screen architecture → reusable DOM/CSS or Pixi component → 9:16 responsive layout → safe-area, touch, overflow, accessibility, and reduced-motion QA. Never port NXR coordinates literally.

## 3D and VFX

Only verified 3D roles enter the 3D pipeline: source study → original replacement modeling → Blender cleanup → GLB/glTF 2.0 → transform, pivot, material, texture, LOD/compression validation → runtime load/performance/fallback QA. A verified 3D effect does not make its scene 3D.

## Promotion

Research reference → original replacement → rights verification → human art approval → runtime QA → Championship 2026 production index. `READY_FOR_RUNTIME` and `SHIPPING_READY` remain separate decisions.
