# Battle static human-paint migration R5

## Scope

This bounded internal-review batch migrates the remaining static shared-ring Battle environments: BM01, BM02, BM05, BM08, BM09, BM10, and BM11. It uses the Owner-approved BM06-C direction as a family style target without treating the seven migrated assets as runtime-approved.

The image generator owns only opaque environment pixels. The R4 BM00 transparent shared layer remains the geometry authority. BM08's verified object layer and BM11's two verified object frames remain separate existing payloads. BM11 keeps its traced two-frame `6 / 6` raw-tick timing.

## Approved visual language

- broad opaque brush blocks with visible overlap;
- broken and lost edges instead of uniformly outlined objects;
- three readable value bands and a quiet central combat floor;
- matte differentiated materials and selective accents;
- natural asymmetry with reduced microtexture;
- no universal rim lighting, glossy toy bevels, or 3D-render finish.

## Hard boundaries

- no generated BM00 border, standing rings, gameplay geometry, characters, UI, text, logos, or franchise symbols;
- no ROM pixels, screenshots, decoded palettes, tiles, cells, or object payloads in generation inputs or outputs;
- no flattening of BM08 or BM11 object-layer responsibility into the generated backgrounds;
- no runtime replacement, production-index registration, or shipping claim in this batch;
- prior R1/R2 candidates remain intact for comparison and rollback.

## Review gate

The seven composites and exact 360x640 layouts are internal review only. Promotion still requires explicit Owner asset approval, a concrete terms/license record, runtime contract binding, runtime QA, and production-index registration.
