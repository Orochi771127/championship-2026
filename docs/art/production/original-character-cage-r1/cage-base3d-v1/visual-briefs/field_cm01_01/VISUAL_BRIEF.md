# field_cm01_01 空地 — Visual brief

狀態：refinement-opus-r5 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，單一六角；放上排時頂端 24px 會被裁掉。
- 4 個來源物件、單格：seq 1 水泥管堆（64×48）、seq 0 樹（48×80，視窗大半在六角外與裁切區）、seq 2／seq 3 木板圍籬（32×64，大半在六角外）。
- 可走範圍：六角中上方的一塊；左側、左下與右下不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：都市空地。泥土地、零星小石、邊緣雜草，前方堆著三根水泥管，後方一棵樹與舊木板圍籬。
- 舊候選（cage-base3d-v1）FAIL 2,893：樹與圍籬畫到六角外。

## 本次原創設計提案

1. **地面**：依遊戲可走格資料，可走區是被踩實的裸土（小石點），不可走區是雜草，兩者以模糊＋雜訊自然交界；不可走格上再放草叢。
2. **水泥管堆**：三根（兩根貼地、一根疊在上面），沿 V 方向擺放，開口朝向觀者並有深色管口；位置落在右下不可走區。
3. **後方圍籬**：舊木板（深淺交錯、高低不一）＋兩道橫木，沿六角右上邊的方向（U）排列，高度由到外框的實際淨空決定。
4. **樹**：圓形樹冠完整收在六角頂角內（配置頁大多被裁掉，只看得到樹幹與樹冠底部），不越界。

## 與近似場地的區別

- 對草原（cm08）：空地的主角是裸土與水泥管，草只在邊緣。
- 對工廠（cm15）：空地沒有機械，只有廢棄建材。
