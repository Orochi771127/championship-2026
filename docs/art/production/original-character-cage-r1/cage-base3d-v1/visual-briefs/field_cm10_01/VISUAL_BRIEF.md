# field_cm10_01 高山 — Visual brief

狀態：refinement-opus-r7 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 288×200，U 形：左上、右上兩個六角＋下方兩個六角；配置頁一定裁掉頂端 24px。
- 7 個來源物件、單格：seq 1 前側欄繩（176×32）、seq 0／2／3 橋頭柱與樁（右側三個帶垂直翻轉旗標，視窗比左側低約 28px，依 `placed_cell_bounds` 原樣使用）。
- 可走範圍（`raising-ground.r1.json`）：兩座山頂台地、各自往下接到橋頭的小路、橋面（五格寬）。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：兩座山頂之間的木板吊橋，下方是深谷與天空；左側橋頭兩根粗柱、右側有一根樁與一根往下的支柱；後側欄繩在核心、前側欄繩是物件。

## Owner 指示（2026-10-06，本輪對話）

- 「橋像是浮在半空；陸地要接到橋面的兩端，橋周圍才是雲。」
- 因此：兩座山頂的陸地一路延伸到橋的左右兩端；天空與雲只在兩個橋頭之間的深谷裡。

## 本次原創設計提案

1. **地面分區**：可走的山頂與橋頭小路是暖色裂紋岩盤；其他陸地是碎石；只有橋頭之間（x 88–200、下半部）是深谷——天空藍底＋低矮體積雲，陸地與深谷交界有一條深色崖壁帶。
2. **橋**：兩根縱梁＋橫鋪木板，橋面跨過深谷、兩端各壓在陸地上 4px；橋面是可走地面，所以維持在地面高度（不抬高，避免與可走格錯位）。
3. **欄繩**：後側（核心）與前側（物件）各有柱、下垂的扶手繩、下繩與垂直吊繩；兩側繩索往回綁到左橋頭柱，右側以斜拉繩固定在右樁上。
4. **橋頭物件**：左後粗柱（含纏繩）、後方錨樁與繩圈、左前粗柱；右側為橋面右後角的矮繫繩樁、右前細樁、右前方陸地上的高繫纜柱。
5. **山頂**：邊緣岩塊（臨深谷較大）、較寬的岩丘、高山草叢與白色小花。

## 與近似場地的區別

- 對小高山（cm37）：同一家族用色；高山是雙峰＋吊橋，小高山是單一台地＋雲海。
