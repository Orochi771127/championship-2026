# field_cm27_01 擂台 — Visual brief

狀態：refinement-opus-r5 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 192×200，shapeMask 14：上方一個六角＋左下、右下兩個六角；配置頁一定裁掉頂端 24px。
- 12 個來源物件、單格、無動畫：seq 1／6 左右角柱、seq 2–5 圍繩段（右側四個帶垂直翻轉旗標，視窗依 `placed_cell_bounds` 計算，不改）、seq 0 燈架 ×2。
- 可走範圍（`raising-ground.r1.json`）：擂台墊面＋擂台前方左右兩塊地面；擂台後方與左右角落外側不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：藍色墊面的拳擊擂台，紅／藍角柱、三條圍繩、前方兩側上台階梯、後方吊燈架、角落椅凳、地上拳套；石板地。
- 原作墊面中央有比賽標誌文字（**不使用**）。
- 舊候選（cage-base3d-v1）FAIL 1,908：角柱與燈架高出六角外框；圍繩是物件格分段。

## 本次原創設計提案

1. **縮小擂台**：四角改為 L(28,116)、T(96,82)、R(164,116)、B(96,150)，讓左右角柱的柱頂留在外框內；檯面 0.28、墊面 0.32 世界單位，深藍裙邊＋白色飾條。
2. **圍繩**：三層連續 3D 直線（中層紅色），在各來源視窗邊界用 `partition_segment` 切分，每段只屬於一個物件；沒有視窗覆蓋的跨距留在核心層（不新增來源格、不移動錨點）。
3. **角柱**：L 紅墊、R 藍墊、T／B 白墊，分屬 ord 0／5／6／9；柱頂 1.45。
4. **燈架**：兩座落地式燈架（雙立柱＋橫梁＋三盞燈），站在擂台後方不可走區，畫在配置裁切線以下。
5. **中央標記**：原創金色八角星＋雙圓環，無文字、無原作標誌。
6. **地面**：可走範圍是較亮的磁磚（像打光區），不可走範圍較暗（後台），由遊戲可走格資料決定，邊界以模糊＋雜訊混合。

## 與近似場地的區別

- 對道場（cm04）：道場是榻榻米與木構；擂台是藍墊、圍繩、角柱、燈架。
- 對健身房（cm05）：健身房是器材；擂台以單一擂台為主角。
