- 功能：單一圓形花壇（中央紅色鬱金香、後側藍白花、前側黃花），四周草地與灌木。

## 本次原創設計提案

- 與花園（cm18）共用同一套花壇、花叢、草地與灌木做法：石環花壇、中央紅色鬱金香、外圈依最近花叢配色的密植花；草地依可走格分亮暗，灌木只在不可走格。
