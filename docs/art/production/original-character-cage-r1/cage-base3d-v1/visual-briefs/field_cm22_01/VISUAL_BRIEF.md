## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：變電站廠區。後方紅白條紋儲槽，深色柏油地面與淺色道路線，鋼構格子塔，掛礙子串的門型架，下方六角是放淺藍配電櫃的平台。
- 電弧物件的錨點都在某個 seq 1 設備正前方 5px：閃電從上方打在該設備的礙子上（大格），平時只剩設備腳邊的小火花（小格）。
- 舊候選（opm-power-refinement-v1）以 frame-00 看是 REVIEW 220，但全狀態包絡 FAIL 1,805（電弧大格越界），且道具是抽象方塊。

## 本次原創設計提案

1. **格子鐵塔（seq 0）**：四腳在螢幕菱形上、腰部收束、兩側面 X 形斜撐、兩層橫擔與礙子串、頂端避雷針；高度依該欄到外緣的實際淨空決定。
2. **門型架斷路器（seq 1）**：混凝土基座、帶散熱片的斷路器箱、三支礙子套管、兩根格子柱＋橫梁、引下線。
3. **電弧（ord 8–11）**：每個電弧配對到錨點最近的 seq 1 設備。cell 5／6：白色主幹＋青色光暈的鋸齒閃電、分岔、打擊點半透明光暈、套管亮點；cell 7：斷成虛線的消散閃電；cell 8：設備基座前的小火花。所有點在設計時就落在各自畫格視窗與六角聯集內。
4. **核心**：深色柏油大板塊與淺色伸縮縫、沿兩個格線方向交叉的淺色步道線、電纜溝蓋、左上後方的紅白條紋儲槽（含頂欄杆與爬梯）、下方六角沿兩條底邊的 L 形配電櫃列（百葉與琥珀色指示燈朝向觀者）。

## 與近似場地的區別

- 對工廠（cm15）：工廠是室內輸送帶與機械手臂；發電廠是露天廠區、鐵塔、礙子與閃電。
- 對瓦斯室（cm23）：瓦斯室是儲氣瓶與管線的室內空間；發電廠的識別是高壓設備＋電弧。
