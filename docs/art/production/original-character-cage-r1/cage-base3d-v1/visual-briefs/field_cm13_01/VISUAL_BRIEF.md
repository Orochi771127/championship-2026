# field_cm13_01 神殿 — Visual brief

狀態：refinement-opus 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 192×200，shapeMask 7：上排兩個六角＋下方一個六角；頂端 24px 在配置頁被裁掉。
- 8 個來源物件：seq 0 大柱 ×4（16×64）、seq 1 雕像 ×2（32×32，其一垂直翻轉）、seq 2／seq 3 火盆各一（16×16，4 格動畫、各 15 ticks）。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：光之神殿。大理石柱廊、後牆拱門與兩側火盆、牆面浮雕，前方大階梯往觀者方向下降，階梯兩側柱頭有天使像，菱形大理石地磚。
- 舊候選（Batch A）的越界主要來自**核心**：台座與鋪面跨過六角之間的缺口（全狀態包絡：總計 3,176、物件僅 300）。

## 本次原創設計提案

在配置頁原生尺寸要能一眼辨認的特徵：

1. **大理石基座＋大階梯**：上排兩個六角是抬高的大理石基座（依六角聯集裁切，外緣內縮；與下方六角的共用接縫不內縮，所以基座前緣與階梯無縫相接），下方六角是面向觀者的六階大階梯，中央深藍金邊地毯延伸到底。
2. **光之泉**：基座後方中央三層台＋金色泉座＋發光球體（原創元素，取代原作的拱門；高大的後牆在本專案的容納規則下會投影出六角頂邊）。
3. **白色列柱＋火盆**：四根帶柱礎、微收分柱身、柱頭與金色環帶的大理石柱；兩座青銅三足火盆，火焰四相擺動。

天使像改為原創的「收翼守護像」（長袍＋收攏雙翼，簡化造型）。

## 與近似場地的區別

- 對寺廟（cm24）：神殿＝白色大理石、柱廊、階梯、光；寺廟＝木構、紅柱、坐像、燭火。
- 對墓地（cm14）：神殿明亮莊嚴，墓地是夜色石板與墓碑。

## 精修（refinement-opus-r14，模組 `cage_opus_sacred_polish_authoring`；r3 的凍結模組不變）

r3 在完整配置頁上的三個問題與處理：

1. **階梯讀成梯子**：r3 六階每階只升 0.064 單位（原生不到 1px），踏面一條條橫線；階梯頂端又沿著上下六角之間的 V 形接縫，看起來像屋頂。
   - 平台高度維持 0.45 單位（原生 4.4px），不改；垂直踢面最多只看得到約 1px。
   - 改法：V 形缺口用一塊與平台同高的「平台口」補平，階梯頂端成一直線；三段石塊踏面（每段兩條錯縫）＋四道短斜踢面（斜面的水平長度 2.5px 加上高度，原生每道約 3.6px 深色帶）；地毯連續包覆每道踢面；欄杆依同一剖面下降，頂端有望柱。
2. **地毯中央黑色菱形**：r3 多一塊地毯方塊與地毯長條同高重疊（共面），Cycles 算成黑色。已移除，地毯只剩一條連續長條。
3. **守護像翅膀是深色尖刺**：翅膀改成面向鏡頭，用微發光的白色大理石材質，讀成白色收翼；兩尊像站在左右欄杆上（左尊在上段欄杆、右尊在欄杆尾端兼作望柱），每尊都在自己的來源視窗內設計，不縮放（量測 1.0，r3 時為 0.8685）。
