# field_cm30_01 小運動場 — Visual brief

狀態：refinement-opus-r15 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，單一六角；14 格高，放在上排時頂端 24px 會被裁掉。
- 1 個來源物件：seq 1（32×32，右側，視窗右緣超出六角）。
- 可走範圍：六角中央；四角與左右邊緣不可走。
- 規格意圖：小型土質訓練區與跨欄；效果與運動場（cm02）相同，是它的小型版本。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：小型土質跑道。整片泥地、彎曲的白色分道線、右側一座跨欄（seq 1）。
- 舊候選（seam-v3）：整片紅土＋幾條白線＋跨欄，平塗，和運動場（r8 已重做）不像同一家族。

## 本次原創設計提案

- 與運動場（cm02，r8）同一套材質與做法：米色泥地、紅色小橢圓跑道（9px 寬、三條白線）、草地內場、起跑線。
- 不可走的角落格放少量圓形樹籬（和運動場右上角的樹籬一致），中央保持留白。
- 物件：seq 1 沿用運動場的紅白跨欄（`cage_opus_sports_authoring.hurdle`），在視窗與六角內設計，不縮放。

## 與近似場地的區別

- 對運動場（cm02）：同家族，單一六角、只有小跑道與一座跨欄，沒有足球門。
- 對競技場（cm03）：競技場是藍色跑道、條紋草皮、看台與燈塔。
