# field_cm21_01 冰原 — Visual brief

狀態：refinement-opus-r11 製作依據（`build-cage-opus-surface.py`，兩格地面動畫）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 240×200，上方兩個六角＋下方兩個六角（錯開）；配置頁一定裁掉頂端 24px。沒有來源物件。
- 地面兩格動畫（各 20 raw ticks）。
- 可走範圍：上半是雪地（terrain 3，遮罩橘色）、下半是一般地面（冰面），左下有可涉水的水域（terrain 2）；後方岩壁與邊緣不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：冰原。後方是覆雪的灰色岩壁，中間厚雪，前方是有裂紋的冰面，左下是有浮冰的冰冷水域（會動）。
- 舊候選（cage-base3d-v1）是平塗灰雪＋藍色水面上的六角形浮冰。

## 本次原創設計提案

1. **三區地面**：雪地格是厚雪（白、微藍陰影、細小閃光），一般地面格是有裂紋的冰面（淡藍、低粗糙度），後方不可走格是岩地。
2. **後方岩壁**：後方不可走格上放多面岩，每塊都先擬合尺寸，再加相同尺寸的雪帽（避免雪帽比岩石大而越界）。
3. **冰冷水域**：獨立的動畫覆蓋層（深藍、斜向波紋、岸邊白色冰緣），兩格之間相位差 π；浮冰是不規則的扁平冰塊，第二格整體漂移約 1.2px。
4. **細節**：雪地上的雪堆、冰面上的冰晶。

## 與近似場地的區別

- 對小高山（cm37）：冰原是雪與冰的寒冷平原、灰藍色岩壁；小高山是暖色岩盤與雲海。
- 對海灘（cm09）：冰原的水是冰冷深藍、有浮冰，岸是冰而不是沙。
