# field_cm20_01 沙漠 — Visual brief

狀態：refinement-opus-r13 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 240×200，左上、中上兩個六角＋右下一個六角；配置頁一定裁掉頂端 24px。沒有來源物件（只有核心層）。
- 可走範圍：幾乎全部；外緣一圈與左下一小塊不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：沙漠。金黃色沙地與風紋、沙丘的陰影、左上角幾塊岩石。
- 舊候選（cage-base3d-v1）：淺色平沙＋幾顆岩石，單調。

## 本次原創設計提案

1. **沙地**：程序化的金黃沙（沿世界 Y 方向的風紋＋扭曲＋微浮雕）。
2. **沙丘**：四座長而低的風成沙丘（壓扁並拉長的橢球），只放在可走沙地的安全位置（高度低，不影響角色站位判讀）。
3. **外緣（不可走格）**：圓潤的砂岩塊（只在外緣，高度由淨空決定）。
4. **點綴**：三株仙人掌（主幹＋兩側手臂）、一個風化的牛頭骨、一叢枯灌木。

## 與近似場地的區別

- 對海灘（cm09）：沙漠沒有水與椰子樹，主角是沙丘與砂岩、仙人掌。
- 對空地（cm01）：沙漠是大片金黃沙，沒有雜草與人工建材。
