# field_cm37_01 小高山 — Visual brief

狀態：refinement-opus-r6 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，單一六角；放上排時頂端 24px 會被裁掉。沒有來源物件（只有核心層）。
- 可走範圍（`raising-ground.r1.json`）：六角中右的一塊；左上、右緣一欄與底部不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：高處的開闊台地。土石地面、零星雜草與小石；台地後方（左上）是天空，右緣是岩壁斷面。
- 舊候選（cage-base3d-v1）把中央做成一座有旗子的石丘，看起來像小山頭／火山錐，與「開闊台地」不符，也容易和小火山混淆。

## 本次原創設計提案

1. **三區地面（依可走格）**：可走區是暖色裂紋岩盤；台地「後方」的不可走格（同一欄的可走格都在它下方）是天空與雲；前方與側邊的不可走格是碎石坡。三區以模糊＋雜訊混合，交界自然。
2. **雲海**：天空區上方放低矮的體積雲，貼著台地後緣，讀起來像「在雲之上」。
3. **台地邊緣**：後緣一排低矮岩塊（只放在天空側的不可走格），右緣是一列較高的岩脊。
4. **細節**：碎石區有散石、左前方有石堆（ケルン式疊石）與無字的風化木樁；台地上有高山草叢、白色小花與小石。
5. **刻意不放**：火山口、熔岩、紅色岩、煙——與小火山（cm35）區分。

## 與近似場地的區別

- 對小火山（cm35）：小高山是灰褐岩盤＋藍天白雲＋綠草；沒有任何紅色或煙。
- 對高山（cm10）：同一家族用色與岩塊；高山有兩座台地與吊橋，小高山只有單一台地。
