# field_cm08_01 草原 — Visual brief

狀態：refinement-opus-r17 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 240×200，shapeMask 11：左上一個六角＋下排兩個六角（L 形）；25 格高，配置頁一定裁掉頂端 24px。
- 2 個來源物件（16×16，錨點在視窗右上角）：seq 0 有兩個姿勢（cell 0／1），seq 1 的影格是 0、1、0。
- 可走範圍：上六角內部與下排兩個六角的大部分；上六角左右兩欄、上六角左下斜帶、下排左側與右側窄條、下排兩個六角的上緣與底尖不可走。
- 規格意圖：大片草地、成簇灌木與草原岩石。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：開闊草原。明亮的綠草地、上六角頂端的岩壁、沿外緣的濃密灌木叢、散落的小灰石、兩叢黃色小花（就是兩個來源物件，會擺動）。
- 舊候選（opm-meadow-refinement-v2）：可讀，但草地像修剪過的草皮，還有原作沒有的踏腳石與花圈石環，和花園太接近。

## 本次原創設計提案

1. **地面**：可走處是有大片深淺斑塊的野生草地，不可走處是更深、更密的草；邊界用模糊的區域混合，看起來像外緣草比較密。
2. **高草與灌木**：不可走格放成叢灌木（雙層圓冠）與高草叢（刀狀葉片網格，全部朝同一個風向傾斜）；只要後方（北側）有可走格，就壓低高度，避免角色站在高物後面卻被畫在前面。
3. **草原岩石**：上六角右側不可走欄是一道帶苔蘚的岩脊（取代原作頂端的岩壁，放在不可走格上）；其他不可走格放兩三塊風化大石；可走草地上只放半埋的扁石（很矮）。
4. **野花**：可走草地上散布白／黃／紫色小花點（很矮）與短草叢。
5. **物件**：seq 0／seq 1 是黃色花叢（沿用花園 r9 的 `flower_clump`），兩個姿勢之間花頭擺動。

## 與近似場地的區別

- 對花園（cm18／cm32）：花園是修剪草皮、花圃、步道與圍籬；草原是野生草地、高草、灌木與岩石，沒有人工結構。
- 對牧場（cm26）：牧場有穀倉、筒倉、圍欄與飼料；草原沒有任何建物。
- 對森林（cm11）／叢林（cm12）：草原沒有樹，植被低而開闊。
- 對空地（cm01）：空地是泥土、雜草與廢棄物；草原是完整的綠色草地。
