# field_cm18_01 花園 — Visual brief

狀態：refinement-opus-r9 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 144×200，右上一個六角＋左下一個六角；配置頁一定裁掉頂端 24px。
- 16 個來源物件：12 叢花（黃色 seq 1／8／9 用 cells 2／3，藍白色 seq 0／6／7 用 cells 0／1；兩格擺動，三格序列以不同起點錯開節奏）、4 個圍籬木樁（seq 2–5，單格）。
- 可走範圍：上台地大部分、斜向的階梯帶、下台地大部分；邊緣不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：兩層台地花園。各有一座石砌圓形花壇（中央紅色鬱金香、外圈黃花或藍白花），兩層之間是石階，石階兩側有木樁圍籬，四周草地與小徑。
- 舊候選（opm-living-refinement-v1）是淺色場地＋水池與木棧道，與花園意圖不符；REVIEW 553，物件越界 32px。

## 本次原創設計提案

1. **草地依可走格**：可走區是明亮草坪，不可走區是較深的草與灌木（含粉色花灌木）。
2. **花壇**：位置與半徑由周圍花叢視窗算出；泥土小徑外圈、低矮石環、深色土壤；中央四圈紅色鬱金香（莖、葉、花杯），外圈密植低矮花叢，顏色依最近的花叢物件（上台黃、下台藍白）。
3. **花叢物件**：每個 16×16 視窗內 6 朵小花（黃色五瓣＋橙心、藍色四瓣＋白心）；兩個姿勢左右擺動，兩個姿勢都在同一視窗與六角內。
4. **石階與擋土**：五塊略有高低的石板階梯（最高 0.12，避免與可走格錯位），兩側不可走格上是低矮石塊擋土。
5. **木樁圍籬（物件）**：每個視窗內找最前方、最高仍合法的位置放 1–2 根木樁＋橫木。

## 與近似場地的區別

- 對小花園（cm32）：同一家族；花園有兩層台地與石階，小花園只有一座花壇。
- 對草原（cm08）：花園是人工整理的花壇與小徑；草原是開闊自然草地。
