# field_cm12_01 叢林 — Visual brief

狀態：refinement-opus-r5 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 240×200，shapeMask 13：左上、中上兩個六角＋右下一個六角；配置頁一定裁掉頂端 24px。
- 7 個來源物件，全部 64×48、pivot (31,40)、單格：seq 0 ×3、seq 1 ×2、seq 2 ×2。
- ord 5 的錨點 (179,198) 落在場地底邊外；樹幹基點在設計時往場內最小距離移動（實際 9px 右、4px 上），錨點資料不改。
- 可走範圍：左上六角大半＋斜向通往右下六角的帶狀區；右側外緣與左下、右下周邊不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：濃密叢林。物件是棕櫚類樹冠（樹幹在原作核心層），地面是深淺交錯的綠色植被，左側有大紅花（大王花），右側外緣有泥土岩壁與樹根。

## 本次原創設計提案

1. **整棵樹當物件**：每個 64×48 視窗放一整棵植物（樹幹＋樹冠）；seq 0 高椰子樹（12 片下垂羽葉＋椰果）、seq 1 矮棕櫚（11 片寬葉）、seq 2 香蕉類寬葉叢（5 片大葉）。每棵在設計時以「最小樹幹偏移、最大樹冠」搜尋落在視窗與六角聯集內。
2. **依可走格分區的地面**：可走區是踩出來的泥土小徑（淺褐綠），不可走區是深色植被；核心層在每個不可走格放兩叢寬葉灌木（較高），可走格只放少量低矮蕨類，避免角色看起來站在灌木上。
3. **大王花**：五片肉質紅色花瓣＋白斑＋深色花心，平貼地面。
4. **泥土岩壁**：只沿兩條垂直外緣（往內升高、不越過外框），不規則岩塊＋苔蘚頂＋垂根與藤蔓。

## 與近似場地的區別

- 對森林（cm11）：森林是溫帶闊葉樹與林下；叢林是棕櫚、寬葉、大王花、濃密深綠與泥土小徑。
- 對草原（cm08）：草原開闊低矮；叢林四周被灌木包圍、只留小徑。
