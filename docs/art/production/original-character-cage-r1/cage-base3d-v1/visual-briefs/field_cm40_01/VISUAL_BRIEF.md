# field_cm40_01 洞窟 — Visual brief

狀態：refinement-opus-r6 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，單一六角；放上排時頂端 24px 會被裁掉。沒有來源物件（只有核心層）。
- 可走範圍：六角左中的一塊；右上、右緣與底部不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：洞窟內部。深藍黑色的岩石地面、後方與右側的岩壁、支撐用的木梁、零星石塊。
- 舊候選（cage-base3d-v1）畫成「洞口」（淺色地面上的拱形黑洞），與洞窟內部的意圖不符。

## 本次原創設計提案

1. **洞內，不畫洞口**：整張是洞窟內部，沒有通往外面的拱門或開口。
2. **地面（依可走格）**：可走區是深色、低反光的岩石地面＋少數低矮石塊與一灘靜水；不可走區是更暗的碎石。
3. **岩壁**：只放在不可走格——後方（可走區上方）與右緣一列多面切割、分層的岩塊，高度由到外框的實際淨空決定。
4. **礦坑木架**：後方兩根木柱＋橫梁＋斜撐，掛一盞暖色吊燈（含小範圍點光源）。
5. **發光晶簇與石筍**：青色、紫色晶簇放在前方與右側的不可走格，各有微弱點光源；前緣有碎石與石筍。

## 與近似場地的區別

- 對小高山（cm37）：洞窟是暗色、封閉、有人工木架與晶光；小高山是明亮天空與雲。
- 對墓地（cm14）：洞窟沒有墓碑與小徑，是天然岩壁與晶簇。
