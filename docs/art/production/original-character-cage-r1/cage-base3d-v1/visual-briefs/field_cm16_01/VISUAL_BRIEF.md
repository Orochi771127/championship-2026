# field_cm16_01 小保健室 — Visual brief

狀態：refinement-opus 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，shapeMask 1（單一六角）；14 格高的籠子放在牧場上排時頂端 24px 會被裁掉。
- 2 個來源物件（seq 7 旋轉椅、seq 1 看診桌），皆為靜態單格；placement／pivot／flip 全部沿用。
- 看診桌的來源視窗只有 64% 在六角內（原作的桌子懸出六角底邊）。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：學校保健室。後方掛軌的藍色隔簾圍著一張病床，左側白色玻璃門藥櫃，體重計，旋轉椅，右下一張看診桌（綠色桌墊、檯燈、文件）。
- 暖米色地板，佈局以靠牆家具＋中央留白為主。

## 本次原創設計提案

在配置頁原生尺寸要能一眼辨認的特徵：

1. **隔簾病床**：白色管架床、白床單＋淺藍毯、枕頭與床頭板；淡藍布簾（有布褶起伏）只遮住床尾與一半前側，讓床本身仍看得見。
2. **玻璃藥櫃**：米白櫃體＋霧面玻璃門，門後隱約可見琥珀、綠、白色藥瓶。
3. **沿底邊的看診桌**：木紋桌面＋米白抽屜櫃、綠色桌墊、三色文件夾、暖光檯燈；沿六角右下底邊配置，不懸出。

材質分區：暖米色塑膠地板（大格接縫）、布料（隔簾、床單）、米白漆、木紋、鍍鉻管件。

留白：六角中央保持空曠給角色活動；高物件（隔簾、藥櫃）距六角頂邊至少一個自身高度投影的距離，保證不越界。

## 與近似場地的區別

- 對醫院（cm17）：保健室是暖色地板＋隔簾病床＋藥櫃；醫院是冷色磁磚＋手術台＋無影燈。
- 對保健室（cm31）：同一家族的單間版本；cm31 是兩間並排（一間有藥櫃、一間有體重計）。
