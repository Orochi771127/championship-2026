# field_cm09_01 海灘 — Visual brief

狀態：refinement-opus-r10 製作依據（`build-cage-opus-surface.py`，兩格地面動畫）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 288×200，U 形（同高山的外框）；配置頁一定裁掉頂端 24px。
- 地面兩格動畫（各 20 raw ticks；時鐘不推定，manifest 的 `coreFrames` 只記原始證據）。
- 2 個來源物件、單格、靜態：兩棵椰子樹（64×64）。
- 可走範圍：左側沙灘（terrain 0）、右側淺海（terrain 2，可涉水）；第一棵椰子樹樹幹所在兩格不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：海灘。左側黃沙與兩棵傾斜椰子樹、沙上一根漂流木，最左緣是草地，下方岸邊是碎石；右側深藍海面有白色閃光，岸邊有浪花。
- 舊候選（cage-base3d-v1）REVIEW 435，物件越界 169px（椰子樹冠超出外框）；海面是平塗淺藍。

## 本次原創設計提案

1. **海面是獨立的動畫覆蓋層**：近岸青綠、外海深藍；波紋沿世界 X 方向（畫面上斜向、大致平行海岸）並有扭曲，兩格之間相位差 π；白色閃光（4D Voronoi，W 隨相位改變）；岸線浪花帶。透明度由海域遮罩決定，沙灘透出。
2. **地面**：沙灘、最左緣草地（只在非本籠格）。
3. **椰子樹（物件）**：沿用叢林的椰子樹（12 片下垂羽葉＋椰果），在視窗與六角內以「最小樹幹偏移、最大樹冠」擬合。
4. **細節**：沙上漂流木與分枝、貝殼與海星；下方岸邊不可走格上的碎石。

## 與近似場地的區別

- 對小海灘（cm39）：同一套海面與沙；小海灘以海為主、只有右側一條沙帶與礁石。
- 對溫泉（cm19）：海灘是開放海面與沙；溫泉是石圈浴池與蒸氣。
