## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：生物研究室。主角是靠後牆排列的**圓柱培養槽**（右上一排、左下一對）。
- 輔助：槽邊的氣瓶、壁掛控制櫃與指示燈、帶波形螢幕的工作台、地上電纜捲與檢修格柵、小型儀器推車。
- 佈局：高物件全部貼著後牆或底邊，中央大片金屬地板留白。
- 原作底邊的工作台會**懸出**六角底邊；本專案的容納規則比原作嚴格，因此不能照搬這種懸出。

## 本次原創設計提案

在配置頁原生尺寸要能一眼辨認的三個特徵：

1. **發光培養槽**：鋼製底座＋細肋柱＋高通透玻璃，內部是飽和的青綠色發光液體，中央懸著一顆金色「種子核心」（原創元素，刻意不做原作那種槽內生物剪影）；動畫為氣泡上升四相＋一個靜止相（液面略降、光暗下來）。
2. **L 型實驗桌**：沿六角底角兩條底邊配置的轉角工作台，後方儀器架上放多色螢幕，桌面有彩色試管。高物件（螢幕）只放在頭頂空間足夠的位置，遠端只留桌面。
3. **深色金屬地板**：沿 2:1 等角格的鋼板接縫，比道具暗，讓發光元素成為視覺焦點。

材質分區：深青灰鋼板地板、不鏽鋼與深鋼（槽座、櫃體）、玻璃、發光液體、白漆實驗桌、綠／藍氣瓶。

留白：左下與右上兩個灣區的中央保持空曠；只有地面級的冷卻格柵（ord 13）放在左下灣區中央，高度 0.1 單位以下。

## 與近似場地的區別

- 對醫院（cm17）：研究所＝深色金屬地板＋發光液體槽；醫院＝明亮磁磚＋手術台與無影燈。不靠換色區分，靠主輪廓（圓柱槽 vs 平台＋圓燈）。
- 對工廠（cm15）：研究所沒有長條輸送結構與工業手臂；工廠的黃黑安全色在這裡只作極小點綴。
- 對毒氣室（cm23）：毒氣室是密封儲槽與管線，研究所是透明可見內容物的培養槽。
