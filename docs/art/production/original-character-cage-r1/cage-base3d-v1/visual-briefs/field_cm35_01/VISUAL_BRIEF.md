# field_cm35_01 小火山 — Visual brief

狀態：refinement-opus-r11 製作依據（家族一致化；舊候選幾何已 PASS）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，單一六角；放上排時頂端 24px 會被裁掉。沒有來源物件；地面只有一格（不動）。
- 可走範圍：左側與中上大部分；右側一帶與底部不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：小型火山台地。岩漿從右上沿右側流下，落入底部岩漿；前緣尖刺岩壁。
- 舊候選（cage-base3d-v1）是一座有粉色火山口的錐形山，看起來像小山丘，岩漿意圖不清楚。

## 本次原創設計提案

- 與火山（cm07）共用岩漿、玄武岩、尖刺岩、暖光與煙的做法。岩漿河從右上沿右側流下；上段穿過可走格的部分是冷卻外殼＋發光裂縫，右側不可走帶與底部是熔岩；可走台地的前緣成排尖刺岩。

## 與近似場地的區別

- 對小高山（cm37）：小火山是黑色岩地與岩漿紅光；小高山是暖色岩盤、藍天與雲。
