# field_cm07_01 火山 — Visual brief

狀態：refinement-opus-r11 製作依據（`build-cage-opus-surface.py`，兩格地面動畫）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 240×200，左上、右上兩個六角＋下方兩個六角；配置頁一定裁掉頂端 24px。沒有來源物件。
- 地面兩格動畫（各 50 raw ticks；時鐘不推定）。
- 可走範圍：中間大片台地；岩漿河上段（頂端中央）與下段、台地前緣以下全部不可走；河的中段（台地中央）是可走格。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：火山台地。深灰火山岩地面，一條發光岩漿河從頂端中央流下、穿過台地，在前緣分流落入下方岩漿海；前緣是尖刺狀岩壁；地面有小石。
- 舊候選（cage-base3d-v1）是灰色六角＋一條沙色裂縫，無發光、無岩漿海。

## 本次原創設計提案

1. **岩漿覆蓋層**：依可走格分成兩種——不可走的河段與前方岩漿海是「熔岩」（深紅結殼板塊、橘黃發光接縫）；河流穿過可走台地的那一段是「冷卻外殼」（暗色、只有裂縫發光），角色走得到的地方不畫成會讓人誤會的液態岩漿。板塊用 4D Voronoi，兩格之間 W 改變，形成流動感。
2. **地面**：可走處是深色玄武岩，不可走處是較淺的火山灰。
3. **台地邊緣**：不可走且緊鄰可走格的地方放多面尖刺岩（前緣成排、像岩壁）。
4. **光與煙**：岩漿河沿線與岩漿海上方放暖色點光源，前方岩漿海上有少量半透明煙（兩格之間微微漂移）。
5. **刻意不放**：藍天、雲、草——與小高山／高山區分。

## 與近似場地的區別

- 對小火山（cm35）：同一家族；小火山只有一個六角、岩漿沿右側流下。
- 對洞窟（cm40）：火山是開放台地與岩漿光；洞窟是封閉岩壁、晶簇與木架。
