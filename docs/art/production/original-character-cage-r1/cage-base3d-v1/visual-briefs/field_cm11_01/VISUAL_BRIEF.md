# field_cm11_01 森林 — Visual brief

狀態：refinement-opus-r12 製作依據（取代 Batch E 的縮小版）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 240×200，右上一個六角＋下方兩個六角；配置頁一定裁掉頂端 24px。
- 9 個來源物件：大樹 ×6（seq 0，48×48）、灌木 ×3（seq 1，48×48，視窗在下緣）。
- 可走範圍：中間的林間空地與右上的一條通道；右上六角後方、左側與下緣不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：濃密闊葉林。大樹冠層層相疊、林下灌木與草，中間是一塊亮綠色的林間空地。
- 舊候選（opm-footprint-refinement-v1，Batch E）：開闊草地上零星幾棵小樹，看起來像草原。

## 本次原創設計提案

1. **地面依可走格**：可走區是踩出來的林間小徑（褐綠），不可走區是深色苔蘚地＋落葉。
2. **大樹（物件）**：樹幹＋三根露出的樹根＋六團樹冠（三種綠），在視窗與六角內以「最小偏移、最大尺寸」擬合。
3. **灌木（物件）**：較小的樹冠團，沒有樹幹。
4. **林下（核心）**：每個不可走格放一叢圓形灌木；可走格只放少量低矮蕨類；右上六角後方的不可走格再加一排較小的樹，讓森林有深度。

## 與近似場地的區別

- 對叢林（cm12）：森林是溫帶闊葉樹與圓灌木；叢林是棕櫚、寬葉、大王花與泥土岩壁。
- 對草原（cm08）：森林被樹冠包圍，只有中間一塊空地。
