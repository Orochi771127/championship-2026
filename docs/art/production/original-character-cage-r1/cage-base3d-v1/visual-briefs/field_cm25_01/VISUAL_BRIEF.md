# field_cm25_01 動物園 — Visual brief

狀態：refinement-opus-r12 製作依據（取代 Batch E 的縮小版）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 192×112，兩個六角橫排；放上排時頂端 24px 會被裁掉。
- 13 個來源物件：後側鐵欄（seq 0／2／3／4／5／11：欄片與轉角柱，視窗大多在上緣與裁切區）、池水（seq 16，cells 16→17→18→17，四步三姿勢）、白色岩堆（seq 13）、木樁（seq 14／15）。
- 可走範圍：中間帶狀區；左中有可涉水的池（terrain 2）；前緣一帶與上緣不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：動物展示區。灰色石板地、四周黑色鐵欄（前緣中央有告示牌）、角落的原木樁、乾草堆、左側圓形水池（水面會動）、右上白色大岩堆。
- 舊候選（opm-footprint-refinement-v1，Batch E）：為了收進外框把道具縮得很小，畫面變成淺色地＋小木柵＋藍色水池＋木棧道，看不出動物園。

## 本次原創設計提案

1. **石板地依可走格**：可走區是石板（Voronoi 板塊＋深色縫），不可走區是碎石。
2. **鐵欄**：前緣（核心，放在不可走的前緣帶）四段鐵欄，柱、上下橫桿、尖頭欄杆；中央一塊素面告示牌（只有爪印圖案，無文字）。後側（物件）每個視窗各自畫欄片或轉角柱，基線沿上緣內縮、高度由淨空決定；左右兩端的視窗幾乎完全在外框外，只放一顆小鐵釘並記錄為來源視窗衝突（不把整根柱縮小硬塞）。
3. **水池**：石圈池緣與深色池底在核心；池水是物件，三個姿勢的同心漣漪依序擴散，另有一個小反光點。
4. **白色岩堆（物件）**：六顆淺色圓石堆成小山（分三層），整組依視窗與六角擬合。
5. **木樁（物件與核心）**：兩到三根不同高度的原木（樹皮＋年輪切面）；乾草堆兩處。

## 與近似場地的區別

- 對牧場（cm26）：動物園是石板＋鐵欄的人工展示區；牧場是草地、穀倉與木柵。
