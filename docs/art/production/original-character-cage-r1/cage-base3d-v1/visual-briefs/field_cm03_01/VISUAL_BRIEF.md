# field_cm03_01 競技場 — Visual brief

狀態：refinement-opus-r15 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 288×200，shapeMask 31：上排三個六角＋下排兩個六角；25 格高，配置頁一定裁掉頂端 24px。
- 6 個來源物件，各自單格：seq 0（40×32，右下）、seq 1（32×32，左側）、seq 2 ×4（16×16：上方兩個、下方跑道上兩個）。
- 可走範圍（`raising-ground.r1.json`）：幾乎整個場地；不可走的是最上一排（y 24–32）、上排兩側各兩格、六角肩部斜帶、下排兩側的窄條，以及 seq 1／seq 0 底下的兩塊。
- 規格意圖：深色競技地面、環形跑道與低矮看台。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：田徑競技場。草地場內、沿外框一圈的棕色跑道、後方一道矮牆、場內有跳遠沙坑、投擲扇形線、左側跳高墊（seq 1）、右下跨欄（seq 0）、四個紅色角錐（seq 2）。
- 舊候選（seam-v3）：配置與原作幾乎一樣（紅跑道＋綠草＋後方欄杆），平塗、沒有看台，和運動場（cm02）同樣是紅跑道，辨識度不足。

## 本次原創設計提案

1. **藍色合成跑道**：三道、12px 寬，中心線用平滑閉合曲線沿場地外框走（外緣離六角聯集邊界至少 3.6px），白色分道線與終點線。藍色跑道讓它和運動場／小運動場的紅跑道一眼分開。
2. **條紋人工草皮**：場內外都是深綠人工草皮，沿格線 U 方向的修剪條紋。
3. **田賽設施（核心層）**：右上跳遠助跑道＋沙坑（木框）、中央投擲圈（混凝土＋白框、止滑板）與兩條扇形線。
4. **低矮看台**：最上一排不可走格，每個上排六角一座兩階看台（藍／白座椅），避開六角之間的凹口；前面一整排彩色廣告板（純色，無文字、無標誌）。
   - 已知限制：這是唯一不可走的後排（y 24–32），而 25 格高的籠子在配置頁一定裁掉頂端 24px，所以實際配置頁上看台大多被裁掉，只剩廣告板一列；原生全圖與物件組裝圖中看台完整。若要在配置頁看得到看台，只能放到可走格上（會被角色蓋過），本輪不這麼做，留給 Owner 決定。
5. **照明燈塔**：上排兩側不可走格各一支，燈頭面向場內。
6. **物件**：seq 0 兩座黑白跨欄、seq 1 藍色跳高墊＋兩支跳高架＋黃黑橫桿（跳高架在墊子右前方，助跑來自場內）、seq 2 橘色訓練角錐（白色反光帶）。全部在自己的視窗內設計，不縮放。

## 與近似場地的區別

- 對運動場（cm02）：運動場是米色泥地＋紅色橢圓跑道＋足球門＋樹籬；競技場是藍色跑道＋條紋草皮＋田賽設施＋看台＋燈塔。
- 對小運動場（cm30）：小運動場是運動場的小型版本（泥地、紅色小跑道、跨欄）。
