# field_cm02_01 運動場 — Visual brief

狀態：refinement-opus-r8 製作依據。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 192×200，上排兩個六角＋下方一個六角；配置頁一定裁掉頂端 24px。
- 5 個來源物件、單格：seq 0／1 跨欄架（32×32）、seq 2／3／4 球門左側、後側、右側（三個相鄰的視窗）。
- 可走範圍：大部分場地與球門內部；右上角一塊、兩個跨欄位置、左右邊緣不可走。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：運動場。泥土跑道與白色跑道線、兩組跨欄、下方球門（三面網架），右上角樹叢。
- 舊候選（cage-base3d-v1）REVIEW 231，物件越界 56px。

## 本次原創設計提案

1. **跑道**：上排兩個六角內的紅色跑道橢圓（直道沿畫面 x、兩端 2:1 半橢圓）、三條白色分道線、起跑線，中間綠色內場；全部依六角聯集裁切。
2. **跨欄（ord 3／4）**：兩種高度與配色（紅白、黑白條紋橫板），腳座朝後；放在遊戲原本不可走的那兩個位置上。
3. **球門（ord 0／1／2）**：白色門框＋網，網口朝上方場地、網後方收窄（配合下方六角的底邊）。每根框管與網線都是連續 3D 直線，用 `partition_segment` 在三個視窗邊界切分，每段只屬於一個物件；橫梁中段因為不在中間視窗內，留在核心層。
4. **地面標線**：球門前的白色禁區線、弧線與罰球點；深褐色泥土地面讓白線清楚。
5. **樹叢**：右上角不可走格上的圓形灌木叢。

## 與近似場地的區別

- 對競技場（cm03）：運動場以跑道＋球門為主；競技場另有跳遠沙坑與投擲區（待後續批次統一家族）。
- 對小運動場（cm30）：同家族配色，小運動場只有單一六角。
