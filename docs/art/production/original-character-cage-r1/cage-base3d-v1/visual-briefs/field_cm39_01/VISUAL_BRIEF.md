# field_cm39_01 小海灘 — Visual brief

狀態：refinement-opus-r10 製作依據（`build-cage-opus-surface.py`，兩格地面動畫）。本文件是美術方向，不是 Owner 核准，也不新增任何玩法、碰撞或可走範圍。

## 鎖定資料（不可改）

- 原生 96×112，單一六角；放上排時頂端 24px 會被裁掉。
- 地面兩格動畫（各 20 raw ticks）。1 個來源物件、單格、靜態：棕櫚葉叢（視窗 56,72 起，只涵蓋六角右下角）。
- 可走範圍：大部分是淺海（terrain 2），右側一條沙（terrain 0）；外圈 28 格是封鎖格（terrain 1，唯一有紅色格子的籠子）。

## 原作研究觀察（本地檢視，未複製、未描圖、未上傳）

- 功能：小海灘。幾乎整片是深藍海面與白色閃光，右側是沙岸，右下角有棕櫚葉。

## 本次原創設計提案

1. 與海灘（cm09）共用同一套動畫海面、浪花與沙。
2. **礁石**：外圈封鎖格上放深色礁石＋苔＋一圈浪花（放不進外框的就不放，不縮小硬塞）。
3. **棕櫚葉叢（物件）**：視窗只到右下角，因此做成貼近水面的低矮扇葉棕櫚（9 片葉），在視窗與六角內擬合。
4. 沙上少量貝殼。

## 與近似場地的區別

- 對海灘（cm09）：小海灘以海為主、沒有椰子樹林與漂流木。
