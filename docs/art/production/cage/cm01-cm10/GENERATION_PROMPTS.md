# CM01–CM10 generation prompts

Tool route: built-in image generation. The approved twelve-module remake board
was used only as a style/camera reference. No ROM image, decoded tile, palette,
layout or object-cell image was supplied to generation.

## Core-field board

Create exactly ten distinct isometric core terrain fields in a 5-column by
2-row contact sheet, ordered CM01 Vacant Lot, CM02 Exercise Ground, CM03 Arena,
CM04 Dojo, CM05 Gym, CM06 Laboratory, CM07 Volcano, CM08 Grassland, CM09 Beach,
CM10 Mine. Show core terrain and permanent structural boundaries only. Preserve
the recognizable original major palette family while changing contours,
materials, markings and construction details. Use polished 2026 hand-painted
2D game art, slightly hand-drawn outlines, clean readable forms, a consistent
isometric camera and fresh bright lighting; Volcano and Mine remain dark but
readable. Do not include detachable props, labels, UI, characters, logos,
watermarks or copied reference pixels. Use an off-white background outside the
ten isolated modules.

## Object-bundle board

Create exactly ten coordinated detachable object kits in a 5-column by 2-row
contact sheet in the same CM order. Kits contain: CM01 weeds/tire/pallet/marker;
CM02 hurdles/cones/starting block/mat; CM03 padded post/rope divider/log dummy/
corner marker; CM04 cushion/low table/lantern/plant; CM05 punching bag/bike/
weight bench/dumbbells; CM06 specimen tanks/workbench/cabinets/instruments;
CM07 basalt spires/brazier/lava rocks; CM08 flowers/fence/shrubs/stones; CM09
palm cluster/beach grass/stepping stones/crate; CM10 timber supports/rails/cart/
lantern/ore crate. Use the same 2026 hand-painted, lightly hand-drawn isometric
style and original-major-palette policy. Request a genuine transparent canvas,
objects only, with no terrain, rooms, text, UI, characters, logos, watermarks or
copied reference pixels.

The generator returned the object board as RGB with a baked visual checker.
The deterministic builder therefore removes only edge-connected bright neutral
background, assigns complete connected objects to their nearest 5×2 cell, and
exports real RGBA packages. The unmodified source board remains retained for
traceability.
