# M201 A Main 0 候選 v1：需要返修

**A 身份保留，姿態和透明度未通過。** 只修透明背景仍不能把這張當成 Main 0 完成品。

Pillow 唯讀檢查：1409×1117、RGB、沒有 alpha 或 transparency metadata。棋盤背景是畫進圖片，並非透明預覽。

與修正 source Main 0 guide 比較，候選主要沿用了概念板站姿：

- 雙手垂在腿旁；來源前肢有前伸與屈肘關係，手端應更高，其中較右手需往左上回復。
- 兩足更低且距離更寬；來源足端前後錯開，不能對齊同一底線。
- 尾端上抬；來源右側尾端更低且突出較少。
- 吻/鼻向左下延伸，頭向與嘴端需要重新對照來源。

以完整畫布正規化做**目視近似估點**（每軸約 ±0.03，不是精準 landmark）：左手來源約 (0.23,0.61)，候選 (0.21,0.71)；右手來源 (0.40,0.65)，候選 (0.48,0.73)；左足來源 (0.29,0.71)，候選 (0.30,0.81)；右足來源 (0.47,0.75)，候選 (0.52,0.82)；尾端來源 (0.59,0.60)，候選 (0.63,0.50)。這些偏差方向不同，不能靠整張移動/縮放補救，也不應據此自動扭曲畫稿。

下一次應將修正 source guide 作為主要姿態輸入，v1 只用來保持 A 身份與乾淨的大色塊。明確指定前伸短前臂、原來的錯開足位、較低短尾與原頭向；保留三角耳、奶油短吻/腹部與銀腕環。不要繼續只美化同一站姿。
