## 共同畫風

- 線條：清楚深色輪廓；暖色身體用深赭、冷色／機械用炭灰。工作尺寸可以有細線，但縮小到實際遊戲尺寸仍須讀得出眼、嘴與肢體。
- 明暗：三個主要明度群，柔和左上光，壓低材質雜訊；高光依附表面，不能跨幀漂移。
- 色彩：先保留來源主色家族，再用臉型、紋樣、材質分區做區別。大幅換色必須作為明確的選案內容。
- 材質：短毛、凝膠、金屬、礦物、植物各用具體邊緣與反光語言。不要所有角色都變成毛茸茸的大眼貓。
- 細節：每隻鎖三至五個識別特徵；優先臉、主材質與大紋樣，不堆細小飾品。概念板底色為奶油紙色；正式圖格另交真正透明 RGBA。
- 鏡頭：用原姿態的朝向與視角。新設定圖不授權改變原動畫的攝影角度、身體比例、移動或碰撞。

## 每隻設計包

角色 ID 與來源 → 兩個不同外觀方案 → 原始标准／極端 pose IDs → 固定識別特徵與色票 → 可改區域／不可改接觸點 → 小尺寸比較 → 推薦與動作風險 → Owner 選案紀錄。

方案 A/B 的區別須在實際遊戲縮圖仍然可辨；不能只是眼色不同。M201 既有金色尖耳候選按可見外觀稱為貓型；新的類犬／水獺等身份需以實際吻部、耳型和臉部結構成立。

## 姿態與圖格製作

以核准角色設定和每個來源姿態共同作為參照。每次處理少量相關姿態；重用同一身份設定，不做彼此無關的單幀提示。不得讓模型補幀、改序列、發明額外動作或為耳尾加新節奏。

先鎖 signed NCER/OAM origin，再確認目前圖集與來源的比例、位置差異。畫布一致不是座標保真證明。平躺、張嘴、縮身、漂浮、黑影和來源中存在的分離零件都要個別檢查，不使用通用「最大連通塊」或「每幀貼底」刪掉／移走有效內容。

允許毛尖、耳形、材質與非關鍵外輪廓在核准範圍改動。接地區、作用端點、軀幹軸向和原始運動軌跡須保持。每幀的幾何目標來自來源與人工 landmark 審核，不能把整套 alpha mask 全鎖死當作造型更新。

在同一角色內，只有来源 RGBA 和對應幾何證明一致的圖格可以共用畫稿。相同輪廓但不同表情／顏色不是同一畫稿。不同角色不能只憑相同 hash 共用新身份。

## 審查責任

- 設計 Agent：身份、造型、色彩與縮圖可讀性。
- 插畫 Agent：線條、材質、表情與同角色跨姿態一致性。
- 動畫／技術美術 Agent：關鍵位置、全圖格覆蓋、原時間軸、資源格式。
- Owner：每四隻集中選案及最終視覺驗收。候選圖與 Agent 推薦均不等於 Owner 核准。
- 主 Agent：唯一正式整合者，確認目前檔案 hash 後合併隔離候選；不覆寫其他 Agent 的共享內容。

只有圖格、時序和視覺皆通過才可進入正常遊戲 QA。缺少 gameplay 動作輸入時保留未接入狀態，不從圖像語意建立 AI／Capture／Battle 規則。
