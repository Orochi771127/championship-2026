# M503 / M419 高清設計後縮為點陣

Owner 最新指示：「這兩隻你先把它變成高清圖重新設計後在縮回像素圖」。M503 隨後指定本輪上傳的原始全身設定圖，先貓化再縮成點陣。此指示適用這兩隻的外觀設計母稿，不代表重新啟用逐動作獨立高清生成。

已使用內建 imagegen 完成兩張 1254×1254 高清稿。M503 以 Owner 的原始插畫作直接參照，保留巨大爪甲、金色肩甲／背盾、銀灰胸甲與原圖站姿，改為金色貓科臉、耳與毛皮。M419 以原生分區研究作姿態參照，設計玉綠龍系、象牙角、深青背脊與奶油腹部。每隻實際送出的文字存於 prompt.txt。

高清原始輸出為 RGB，包含繪出的棋盤背景；不能稱為透明 PNG。保留原檔 hd-generated.png，另以邊界連通的亮中性色移除背景，產生 hd-cutout.png。輪廓內的白／銀甲面沒有做全圖去白。去背後再以單一等比縮放縮入原生畫布，BOX 取樣、15 個可見色量化、不抖色、alpha 0/255。放大預覽使用最近鄰。這裡的縮小置中是外觀研究用，尚未按來源 NCER / OAM 對位。

- M503：48×56 原生畫布；hd-cutout.png、pixel-native.png、pixel-indexed.png、pixel-preview-10x.png。
- M419：32×32 原生畫布；同上檔案。
- conversion.json 記錄裁切、等比縮放、放置位置、色數、alpha 與實際檔案雜湊。
- setting-candidate.json 保留來源 slot / native bounds 作後续製作參照；僅為候選，沒有登記到目前正式設定或角色包。
- pixel-material-palette-study.png 是另一個色盤的比較研究，不是目前採用結果。

高清圖能看清部位，不等於直接縮小後細節已完全可讀。M503 的眼口、胸甲接縫和爪間隙，M419 的眼睛與指爪，仍需在原生尺寸評審與像素修整。高清插畫與原生遊戲畫格姿態有差異，因此動作原點、端點與透明支撐尚未通過。不得切換遊戲預設或宣稱完整動作相容。

之前直接畫原生像素的分區研究保留於 ../../_work/readability-large-r01（相對本文件實際應由 appearance-refresh-v1 根目錄解析），其獨立審查不繼承為本輪 HD→pixel 結果通過。224 全員計畫仍保留；這次沒有新增已驗收設定或正常遊戲替換數。
