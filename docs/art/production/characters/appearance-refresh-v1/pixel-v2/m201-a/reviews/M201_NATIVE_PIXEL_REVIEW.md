# M201 A 原生像素設定與九槽下部 patch 評審

本輪依最新 Owner 方向改用 source-native pixel art。M201 A、M001 B、M226 B、E000 A 選案不變；停止以獨立高清生成圖作動作母版。以下是 pixel-bank 的設計建議和來源唯讀檢查，不是已完成畫稿或相容 PASS。

已實際檢視修正 Main 000／002 guides 與 A 身份的高清 v3。A 的完整大眼、耳內毛、鬚線、銀腕環與手趾，不可能同時完整塞入 16×18 可見範圍。應保留身份優先級，不能把高清全部細節逐一硬塞入。

**來源格與差異證據**

- OAM 主塊 16×16，source x=-8、y=-19；下塊 16×8，source x=-8、y=-3。合起來為 16×24 的同一原點格。
- Main 000 目前 rows 0–2 全透明，visible rows 3–20；rows 21–23 透明。行列在本文件均為 0-based。
- Main 000 與 Main 002 經修正 guide 以 12×倍率格心唯讀採樣，差異僅 **columns 7、8、9 × rows 5、6 的六像素區**；其餘採樣完全相同。
- 因此這對候選可以共用同一頭部 glyph，只變更對應小眼區。此事只證明來源局部視覺差異，不能據此命名眨眼或推定觸發語義。其他 variants 須各自查 delta，不能自動都套同一模式。

**建議 10 個可見色，另留透明 index 0**

| 建議 index | 色值 | 功能 |
|---:|---|---|
| 1 | `#3A2A1B` | 外輪廓、眼、鼻、必要分隔 |
| 2 | `#8A591E` | 金毛暗部和背側 |
| 3 | `#D49A25` | 主金毛 |
| 4 | `#F4C647` | 受光金毛 |
| 5 | `#C8AA70` | 奶油區暗部 |
| 6 | `#F1D69A` | 奶油短吻、胸腹、趾端 |
| 7 | `#FFF1CF` | 一點眼光／必要淺色端點，可與趾端共用 |
| 8 | `#666B6E` | 銀腕環暗側，禁止轉用成新腳環 |
| 9 | `#A5AAA8` | 銀腕環可見亮側 |
| 10 | `#B67436` | 可選一像素耳內暖色，不够空間可不用 |

這是美術指定目標，不是來源取色的硬性新權威。10 色足够，不必用滿 15 色。不要增加粉紅舌、獨立白眼框、金屬亮白等只為單個 pixel 存在的顏色；特定狀態的整體色變仍跟隨來源約定。

**身份優先與可行簡化**

1. **三角耳是最強的新輪廓訊號。** 可以在主塊原本上方三行透明餘量內嘗試兩個短峰，每峰約 2–3 pixel 高；主要頭部左右範圍內保持谷口。不能擴成超出 OAM 格的新 canvas，也不能移動下方頭/手/足來騰空間。若雙耳擠成王冠，退為一個清楚近耳＋較小遠耳，保留同一頭部側向。
2. **奶油短吻與單側眼優先。** 嘴端仍是來源位置；在既有金色吻區內用 2–4 個連續奶油像素形成短臉，不能加長鼻。眼以深色 2–3 pixel 群和最多一亮點為目標，不能為放大眼移走來源六像素差異區。
3. **奶油胸腹採單一連續色群。** 在來源軀幹內部改色，保留外側金毛與肢體分隔；不用腹部毛紋、不畫衣服或圍兜。
4. **腕環只留可見的一至兩個灰 pixel 暗示。** 每格可見表面不足就以灰帶局部段表示，不能畫成完整大環、迫使腕部位移或把足部淺點一起染成銀環。
5. **刪除高清細節。** 鬚線、小虎牙、碎毛斑、耳內多層、反光和三個獨立趾甲不要求全部保留。保留金毛、耳、短奶油吻、胸腹、腕灰五組身份的可讀取捨；A 不因此改選。

**九槽共用下 16×8 patch 的作用**

以 guides 的固定座標 `(88,232)–(280,328)` 讀取 12×下塊，RGBA bytes 與 Main 000 完全相等者恰好九槽：

`Main 000、002、004、006、011、015、021；Sub 000、002`。

這是座標和 byte equality 的 reuse 證據，不是依肉眼看似相同去重。下 patch **不只有腳**：

- 全格 row 16 尚含較近側手／腕的淺色端點與身體/肢體分隔。
- rows 17–19 含下腹、腿與前後錯開的淺色足端。
- row 20 有右下方暗色底部輪廓；rows 21–23 透明。

因此可共用一次人工重繪的下 patch，再回填這九槽，前提是同時保留手端、足端、透明洞與輪廓。不能把它視為「腳部貼紙」重新對齊底線，也不能用整塊奶油腹色填滿。主塊 row 15 与下塊 row 16 是腕/軀幹交界，色帶與輪廓須連續，不能在 seam 多畫一條深線。

**看到 root 畫稿後的驗收次序**

- 先在 1×看是否能讀出金色貓型的新身份，再看 8×或 12×是否只是漂亮大像素圖；認不出就記身份需返修。
- 對原格檢查手/足端、透明洞與共同原點；加耳可局部改輪廓，但不能改肢體拓樸。
- Main 000／002 除指定局部眼區外不允許無理由的頭形、耳形或腹色漂移。
- 九槽下 patch 必須保持同一新 pixel bytes，而不是九次手工近似複製；仍須整格合成看 seam 和遮擋。
- 顏色數和 alpha/索引是技術檢查；它們通過也不代表角色身份或動作通過。
