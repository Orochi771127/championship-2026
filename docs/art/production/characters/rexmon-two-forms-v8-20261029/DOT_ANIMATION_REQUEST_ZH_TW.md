# 給 dot：雷克斯獸雙形態動作需求（2026-10-29）

來源：Claude Code 依目前遊戲 runtime 整理。完整欄位見同資料夾的 `ANIMATION_REQUIREMENTS.v1.json`。Codex 只負責歸檔與檔案核對。

## 先說現況

- 這批 v8 包只有設計主圖、三視圖與參考圖，兩個形態都**還沒有任何動作格**。
- 遊戲裡兩型目前只出現在圖鑑：243 雷克斯獸（UL41）、244 雷克斯獸·戰鬥型態（UL42），兩者都是究極體。它們不能登錄、不能養成，也不會出現在 Data Arena。
- 動作美術請以 v8 主圖與三視圖為準。龍形三視圖檔名雖是 v6、龍形主圖檔名是 v7，都是 v8 manifest 選定的版本。v7 人形背炮方向已作廢；v1 雙型圖只供故事模式立繪參考。

## 兩型各自需要兩套

### A. 一般遊戲（牧場養成、捕捉、對戰結算）

Main 0–39 與 Sub 0–12，共 53 個槽位都要有對應動作。同一形態的已審動作可以透過明確別名共用，不必畫 53 組不同的圖（UL02 用 33 個姿勢涵蓋 79 個槽位）。

- **Main**：待機、虛弱待機、走、跑、捕捉彈跳、放下落地、受擊、近戰 ×2、遠程、被抓起、虛弱走（至少兩張左右腳相反的疲憊接觸姿勢）、睡、吃、倒下、綁縛系列（待機、虛弱、走、快走、彈跳、掙扎、虛弱走、睡、吃、倒下）、擊退、防禦、被摸滿足、不適、訓練、不悅拒絕、受驚、勝利，以及其他受擊與防禦槽。
- **Sub**：中立、虛弱、攻擊、受擊、睡、倒下、滿足、不悅、勝利、休息、拒絕。
- 時序（每段 stop 或 loop、每格 ticks）目前沒有指定來源，等 Owner 決定 motion donor 或原創時序後補上。

### B. Data Arena（八方向：下、右下、右、右上、上、左上、左、左下）

| 動作 | 每方向 | 規則 |
|---|---|---|
| 走動 move | 循環 | 依移動速度推進；幾乎靜止時停在第一格 |
| 近戰 melee | 單次 | 第 0 格是**前搖姿勢**，會停住等到招式真正釋放（CAST_RELEASE）後才播後面的格 |
| 遠程 ranged | 單次 | 同上；請標出**釋放格**與**發射點**，特效從那一點出現 |
| 受擊 hurt | 單次 | 依被打時面向；可附回位姿勢（neutral return） |

另需兩項：倒地 KO 用一張靜態格，經核准綁定；沒核准時會停在受擊最後一格。勝利 win 只需朝下一個方向，可選；沒有時會用朝下的遠程代替。

最少 4 種動作 × 8 方向 = 32 段，另加 KO。

## 必守

- **戰鬥型態左右不對稱**：磁軌砲是角色自己的右臂，左手是兩指爪。不能整張左右翻轉，翻轉會把砲換到左手。朝左的方向都要另外畫。
- **背炮固定不旋轉**：炮口和橘色發光槽朝後，只有從背後看得到。正面看到的是封閉的象牙／深青綠殼背，右側視只看到朝後的窄緣。不可正背兩面畫成同一個炮口。
- **龍形**：外觀接近對稱，但鏡像方向仍要你視審核可後才能用。
- **手腳**：龍前手兩指；人形左手兩指爪；兩型的腳都依三視圖是三趾，不要改成兩指。
- **眼睛**：真正的頭部眼睛有眼白、虹膜與瞳孔；戰鬥型態胸口龍首的兩眼是寶石甲件，沒有眼白和瞳孔。
- 不能拿主圖重複、鏡像或縮放冒充動畫，不能借其他角色已驗收的動作，也不能用一般遊戲的圖填 Arena 八方向。
