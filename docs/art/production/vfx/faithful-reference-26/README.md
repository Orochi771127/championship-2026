# Faithful VFX reference conversion — 26 systems

All 26 `NITRO_3D_VFX` systems in the art registry are represented here as a
deterministic Web-format reference conversion. The package contains GLB models,
decoded animation tracks where supported, textures, source hashes, and explicit
format gaps.

This is not a runtime or shipping bundle. NSBMA/NSBVA data and code-driven
trigger timing remain unknown where the converter cannot prove them. The files
therefore stay under `docs/art/production`; only a separately licensed,
human-approved and runtime-QA-passed bundle may be registered under
`assets/production`.
