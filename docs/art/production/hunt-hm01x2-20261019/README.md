# HM01 戴納草原：整張統一重建（約兩倍可探索面積）本機審查候選

狀態：`LOCAL_REVIEW_ONLY`。只在 loopback 加 `?huntReview=hm01x2-20261019` 時啟用，正式／公開流程不變。未發布、未合併 main。

## 做了什麼

- 整張 180×180 格（2880×2880 世界像素）用同一個 R11 Blender 管線一次渲染：同一套樹冠、草、岩壁、光源與鏡頭。沒有舊圖加新區的硬接縫，日夜共用同一地形與物件配置。
- 原 128×128 的功能結構保留在原座標（舊→新為恆等映射）。新增的範圍是東側（湖往東擴、湖中小島、溪流、蘆葦池、東林、有兩個缺口的蜿蜒稜線、兩個東出口），以及南側（第三個洞穴台地、白樺林、西南小池、低稜線、兩個南出口）。
- 原南側林帶開兩道缺口（x18–27、x76–81），舊東緣第 127 欄與舊南緣第 127 列改為內部地面，讓新舊草地連成一片。舊林塊碰到舊邊界的直線處，改成圓滑林緣伸進新區。
- 現實錯置地標：草丘上一節沒有鐵軌的老式電車車廂（綠／奶油色）。
  - 車輪陷入草土，前轉向架有樹根纏繞，裙邊長苔。
  - 一株藤蔓爬上車頂，車頂積了苔與落葉，前沿掛著票旗。夜間兩扇車窗亮暖光。
  - 旁邊有站牌、木長椅、白色資料終端和綠色機櫃。
  - 車廂只是阻擋格上的景物，不提供乘坐、商店或郵件功能。
- 品質提升：
  - 水：自繪清澈水底（沙、卵石、水草）、隨深度變化的焦散光紋、綠松色到深藍的漸層、碎浪泡沫線與外圈波紋線。
  - 草地：成片野花叢。

## 精修階段（2026-10-19 第二輪）

使用者回饋：地形太粗糙、草地要柔和綿密、小花太雜；原作有石頭與泥土地，可參考變化但不要照抄形狀；草地上插著的販賣機、郵筒是「不屬於那個世界的物件」；整張要同一風格。

粗糙原因（與原作、參考圖同倍率比對）與修正：

| 原因 | 修正 |
|---|---|
| 草地只有低頻色雲，沒有草葉尺度細節，看起來糊 | 細密短草：每 2 px 一叢，色調接近地面，柔和、綿密 |
| 色雲偏暗，像柔焦陰影，整張灰濛 | 移除暗雲，只保留輕微色調變化 |
| 缺少原作的地面語彙（泥土地、碎石、茂草、三葉草、小石頭） | 自行設計地面分類：連接三個洞口、電車站、湖岸與出口的踩踏土徑；兩處有碎石芯的大片空地；崖腳林緣的茂草；水邊的三葉草（只有這裡有少量白花）；土徑邊與空地的小石頭 |
| 散落小花太雜 | 移除全圖散花，花只出現在三葉草叢 |
| 崖頂依 8 px 格呈階梯 | 圓滑崖頂輪廓，只向阻擋格內縮（部分狹窄稜線仍有階梯感，列為待修） |
| 渲染顆粒 | 128 samples 加降噪 |
| 販賣機、郵筒像抽象機櫃 | 改為真正的白色販賣機與綠色郵筒，微傾、陷入土中，底部有土堆與草圈，與電車同一材質語言 |

- 地面分類是自己的設計（`source/design_ground.py`）。原作只用來理解有哪些地形變化，沒有逐格照抄。
- 地形、功能、洞穴通道群組都不變。測試 8/8；正常流程日夜都能進場（`refine-ingame.jpg`），桌機 p95 16.8 ms。
