# A1 Cage Original-Structure Receipt

Outcome: **40/40 structure rows classified; original construction adopted.**

The Owner directed the remake to follow the original Cage terrain construction.
The original evidence confirms a core tile field plus a separate object bundle,
with independent ATR and COL data. The proposed four-way semantic PNG split is
therefore rejected as a runtime architecture. The twelve approved concept
modules remain visual-direction material only.

## QA result

- 40 unique CM ordinals and 40 unique `field_cm01_01`–`field_cm40_01` IDs.
- Four production batches of ten.
- All forty rows preserve verified variable dimensions and layout-cell counts.
- CM28 and CM29 declare no native object layer.
- CM12 and CM18 retain `ORIGINAL_OBJECT_INDEX_CONFLICT_DO_NOT_INFER`.
- Every row is `REFERENCE_METADATA_ONLY_NO_ORIGINAL_PIXELS` and
  `NOT_RUNTIME_READY`.
- No gameplay effect, raising value, ATR meaning or COL meaning was invented.

## Classification

- Production visual package: `core-field` + `objects`.
- Nonvisual data package: `atr` + `col`.
- Optional occlusion/foreground behavior: object metadata after the rendering
  contract exists; never inferred by slicing a flattened image.
- VFX: separate licensed-source conversion package, not baked into terrain.
