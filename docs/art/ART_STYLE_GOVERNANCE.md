# Championship Art Style Governance

> Art-A evidence-translation rules for Championship 2026. No visual replacement batch is authorized by this audit.

Every production brief must lock camera angle, perspective, lighting, outline treatment, material language, texture density, saturation, value hierarchy, character-to-environment scale, UI frame language, VFX language, shadow style, foreground occlusion, background detail density, and animation exaggeration.

## Source translation

- Preserve system DNA, composition roles, information hierarchy, timing, and semantic function.
- Do not ship source pixels, textures, geometry, branding, or ROM conversions.
- Verified 2D becomes high-quality layered 2D; verified 3D becomes scene-bounded 3D or hybrid; unknown media remains blocked.
- Project-native characters use approved illustrated masters, transparent backgrounds, stable silhouette and scale, bottom-center ground contact, and consistent lighting.
- UI is single-screen, mobile-first, touch-first, safe-area aware, and protects the playfield. Avoid DS dual-screen reconstruction and generic dashboard chrome.

Generated art must pass identity and cross-asset consistency review before any runtime promotion.
